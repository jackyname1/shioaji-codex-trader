# Shioaji Codex Trader

Shioaji 真實行情、Codex 策略、監測清單與持倉同時顯示的桌面交易工作台。內建券商連線，登入一次後，模擬與實盤共用連線、Codex 及設定；歷史模擬不受實盤帳務載入影響，實際下單時需要有效 CA。

![行情工作台](docs/screenshots/workbench.png)

## 功能

| 功能 | 說明 |
|---|---|
| API 與憑證 | 內建 Shioaji，輸入 API Key、Secret Key 即可連線；記住設定後，下次開啟自動連線。實盤下單需有效 CA。 |
| 模式工作台 | **即時模擬**以真實行情與虛擬資金演練正式流程；**歷史回放**集中日期、本金、回放時鐘與損益；**實盤**顯示真實帳戶與委託。Codex 常駐右側。 |
| 行情圖表 | 分鐘、5／15／60 分與日 K，即時五檔，搭配 MA5／20／60、波動帶、RSI、成交量、保護價格和模擬成交標記；支援滑鼠拖曳、滾輪縮放、價格軸縮放與時間軸，更新行情保留檢視位置。 |
| 歷史模擬 | 指定起訖日期、時刻和本金，終止時間最晚到現在；歷史行情分段下載、快取並保存，可匯出完整資料。 |
| 回放控制 | 暫停、繼續、單步與 1×～3000× 加速；「直達觸發點」只略過等待，每次 Codex、條件設定、送單與核對仍完整執行。 |
| 策略比較 | 預設 Codex 每日選股與自動設定條件，也可切換程式策略驗證；同一段資料可比較不同分析間隔，查看損益、資產曲線、回撤、費稅及成交紀錄。 |
| Codex | 共用登入；解析官方目錄的實際預設模型與推理強度。完整顯示官方推理摘要、快照、原始決策、用量與送單結果，支援搜尋及完整 JSON 匯出。 |
| 動態監測 | 以 5–20 檔合格觀測股為目標；沒有合格股可保留現金，不強制補股。顯示進場、停損、停利、移動停損與原因；持倉及掛單持續保留監控。 |
| 選股資料 | 回放與即時掃描均取高成交金額端排行；優先使用官方 K 線成交金額。Codex 紀錄顯示股票池、歷史就緒數、基本資格及每檔資料失敗原因。 |
| 交易管理 | 定時執行快照、選股與條件設定；短週期偵測條件，觸發後再詢問 Codex 股數，重新核對現金與風控才送限價單。成交、可賣庫存、交割款與撤單持續核對。 |
| 實盤連線 | 選擇實盤後自動取得帳務，CA 與帳戶核對完成即可使用；「開始自動交易」只控制策略自動執行，不需額外授權對話框。 |
| 桌面操作 | 深色工作台、無字母的軌道與四芒星圖示，以及待命／執行／暫停／離線系統匣狀態；可背景監控、暫停買進及緊急停止。 |

即時模擬與實盤使用截至現在的行情；歷史回放的 AI、指標與監測清單只使用截至當下虛擬時間的資料。三者使用相同的條件、數量確認與交易風控流程。

## 開始使用

1. 下載 [v0.1.0 預發行版](https://github.com/jackyname1/shioaji-codex-trader/releases/tag/v0.1.0) 的 Windows 免安裝程式並開啟。
2. 按右上角「帳戶與設定」，輸入 API Key、Secret Key，再按「登入並記住」。預設以系統加密記住，下次自動登入。要啟動實盤下單時，一起選取 CA 憑證並填入密碼。
3. 按右側 Codex「登入」，在瀏覽器完成後自動測試連線；模型留空自動解析官方預設，畫面會列出實際模型及推理強度。已保存的登入共用於模擬與實盤，Key 與 CA 密碼再次開啟設定時會填回密碼欄位。
4. 在「模擬 → 即時模擬」按「開始自動交易」，使用真實行情與虛擬資金演練；在帳戶設定選擇每日固定時間或分析間隔，條件預設每 3 秒偵測。若要測試過去的交易日，切到「歷史回放」，設定區間與本金後開始「Codex 每日選股」，也可選「程式策略驗證」測試流程。
5. 選擇「實盤」即可查看帳戶與委託。CA 與帳戶核對完成後自動就緒；需要自動執行 Codex 策略時，按「開始自動交易」。

重啟或重新連線會重新核對帳戶，自動交易保持關閉。「停止交易」會立即停止新委託，不會自動撤銷券商掛單，也不會被背景重試解除。餘額、交割與持倉各自更新，單項查詢失敗仍保留已取得資料；帳務不完整時不送出新委託。

## 開發

```bash
npm ci
npm test
npm start
npm run pack:win
```

需要 Node.js 24 以上；開發啟動與 Windows 打包時會取得並驗證官方 Shioaji。設定與報表保存在本機使用者資料目錄，無需固定自選股或 `config.yaml`。
