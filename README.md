# Shioaji Codex Trader

**v0.2.3 開發驗證中，尚未發布** · [目前可下載 v0.2.2](https://github.com/jackyname1/shioaji-codex-trader/releases/tag/v0.2.2) · Windows x64 免安裝

台灣股票桌面工作台：以 Shioaji 取得行情，讓 Codex 設定選股與買賣條件，由程式核對價格、股數、現金及風控。提供即時模擬、歷史回放和實盤帳戶介面；歷史測試使用獨立虛擬帳戶。

## 這版更新

- **回檔、趨勢、突破三路進場。** 程式方案與模型方案同股競爭，優先選擇已確認且通過成本／風控的方案；共用委託識別防止重複下單。兩筆不同時間的實際價格確認、追蹤低點、逾時與失效狀態均會保存。買價上限、停損及有證據的目標價在訊號建立時固定，不因拒單上調。
- **ATR 移動保護與含成本保本。** 補上未使用的移動退場；追蹤最高價，啟動後保護價只向上，停損／保本／移動訊號有明確優先順序。部分賣出保留狀態，全部賣出才清除；重啟及跨日繼續追蹤。
- **按機會分配資金。** 依訊號、扣費報酬風險與可用預算排序，70% 是軟性目標。小單先檢查雙邊最低手續費、稅、滑價及淨利門檻；待交割賣款不算立即購買力，原有硬性上限保留。
- **更完整的成交與異常處理。** 下一個價格事件才可能撮合，受限價、深度、漲跌停與滑價約束。成交後按實際股數再核對風險；日損失達限當日鎖定新增買進，重啟不解鎖。未知候選只容許一次完整重新分析，不截掉股票冒充完整策略。
- **UI 與可重現驗證。** 持倉點選同步主圖和來源，顯示成本、持有／可賣量、未實現毛利及保護狀態；重要智慧條件優先顯示。新增五組比較、Profit Factor、費稅、退出觸發及閒置原因分布。
- **預設模擬。** 一般啟動進入模擬工作台；新模擬帳戶預設綜合策略與積極資金配置，升級既有模擬帳戶保留原資金參數。實盤需手動選擇及授權啟動；本版沒有開啟真實自動下單。

原始 v0.2.2 JSON 已核對：期末權益 **100,589.5 元（+0.5895%）**，已實現 **864.5 元**、含已付買進費用的未實現 **−275 元**，費稅共 **1,053 元**。20 個盤後快照平均持倉 **41.8518%**，期末 **4.2052%**；期末另有 **42,696 元待交割賣款**。40 個買進提案全未設定移動退場，且有重複風控阻擋及一筆未知候選失敗；低投入並非單一參數造成。

[完整根因、參數與五組比較](docs/V0.2.3_VALIDATION.md)分開列出原始紀錄、稀疏觀測回放及合成驗證。JSON 沒有完整分鐘價格路徑，無法忠實重跑同一場 Codex 回測；部分資料及虛構行情的結果不代表新版真實市場獲利改善。

## 開始使用

1. v0.2.3 尚未完成發布；目前可從 [v0.2.2 Release](https://github.com/jackyname1/shioaji-codex-trader/releases/tag/v0.2.2) 下載已發布程式。先從舊程式系統匣選擇「結束程式」，再開啟新版；單一執行個體機制會把再次啟動導回仍執行中的舊版本。右下角可核對實際版本。
2. 按右上角「帳戶與設定」，輸入 API Key、Secret Key，再按「登入並記住」。實盤下單另需有效 CA 憑證及密碼。登入與設定共用於模擬和實盤。
3. 按右側 Codex「登入」，完成官方瀏覽器登入並按「測試連線」。模型留空時解析帳戶預設模型；畫面顯示實際模型及推理強度。
4. 在「模擬 → 即時模擬」演練目前行情。要使用過去行情，切到「歷史回放」，設定起訖日期、時刻、本金及排程，再開始「Codex 每日選股」。
5. 「實盤」顯示真實帳戶及委託；按「開始自動交易」並完成授權才啟動策略；一般重啟預設回到模擬。重啟、重新連線及解除 Codex 故障都不會自行解除停止狀態或繞過交易風控。

## 歷史回放怎麼運作

| 階段 | 行為 |
|---|---|
| 每日股票池 | 使用前一交易日的歷史成交金額排行，保留當日實際合格成員，上限可設定為 20–100 檔；累計聯集可超過 100 檔。也可指定最多 100 檔固定股票。 |
| 指標暖機 | 入池前的行情整理成每日 OHLCV 與成交金額，計算 MA、RSI、ATR 等。模型及指標只讀取虛擬時間之前的已完成日 K。 |
| 策略 | 可選 Codex 或快速程式策略；綜合模式另比較三路程式進場。目標監測 5–20 檔，沒有合格機會可以保留現金。 |
| 條件監測 | 預設一般進場也逐筆檢查可用價格事件，可切回五分鐘排程；股票池每五分鐘更新，反彈與持倉保護逐筆檢查。 |
| 股數與風控 | Codex 方案另核對實際股數；程式方案按當時預算計算。最終數量、限價、費稅、現金與可賣庫存必須再次通過風控。 |
| 播放控制 | 「直達觸發點」依序處理事件；「加速播放」支援 1–60 倍。暫停、分析及股數確認期間凍結虛擬時間。 |
| 故障與結果 | 執行故障保存 PARTIAL 結果並停止後續模型呼叫；稀疏觀測資料也明確標記 PARTIAL；不以未完成期間的結果冒充完整回測。 |
| 匯出 | 完整 JSON 包含已保存分鐘行情、暖機日 K、每日股票池及入池日期；CSV 僅含保留的分鐘行情與成交金額。成交明細另有 CSV。 |

日期最多 367 天；分鐘行情及暖機日 K 合計最多 300 萬筆。超過資料量上限會明確停止，需分段回測；每日排行不會因此被截斷。歷史下載維持每次最多 30 個日曆日、快取及節流。

日 K 圖可查看暖機資料；分鐘圖顯示每檔入池後保留的分鐘行情。歷史零股五檔、排隊、滑價及企業行動仍有近似限制，策略小樣本與虛構測試結果都不能當作實盤獲利證明。

## 反彈買進與智慧退場

模型方案按當時快照設計；開啟綜合進場時，程式也會依已完成日指標建立反彈、趨勢與突破方案，凍結價格界線後用實際新鮮成交確認。以下為機制示例。

| 條件 | 設定與例子 | 程式行為 |
|---|---|---|
| 反彈買進 | REBOUND、門檻 100、回升 2% | 先跌至 100 才追蹤；低點降至 96，回升至 97.92 才提案，仍受買價上限和 AND 條件約束 |
| 移動退場 | 啟動 110、回落 3%、固定停利未啟用 | 越過 110 不直接賣；高點 115 後跌至 111.55 才提案 |
| 固定停損 | 停損 95 | 價格到 95 或以下優先提案，不等反彈；跳空仍按可用價格與限價風控核對 |
| 含成本保本 | 浮盈達 0.5R 且足以涵蓋成本與波動 | 保護價上移以估計覆蓋買進費用、退出費稅及滑價；隔夜跳空仍可能虧損 |
| 收益目標 | reward_target=115 | 僅估算費用後收益／風險，不觸發賣出；若也設固定停利，成本採兩者較低值 |

追蹤只使用新鮮且不超過現在的已觀測成交價；舊行情不啟動新策略，重啟保留當輪低點，整股與零股分開追蹤。程式方案預設兩筆相隔至少 30 秒的成交確認、120 分鐘逾時；相同有期限訊號可延續原低點，換價位、跌破停損或逾時則失效。既有持倉的停損與已啟動移動保護不放鬆，空倉的新部位不沿用已賣出部位的舊高點。

分鐘回放只使用每筆收盤價，不假設 K 線內的價格路徑；只有日 K 時無法驗證盤中智慧條件。今日買進零股不可當沖，停損、移動退場及觸發價均不保證成交。歷史保護無需額外 Codex 股數確認，但行情／帳務失效、模型故障停止、緊急停止及既有委託核對仍會阻擋送單；模擬的綜合保護可依可賣量直接執行；實盤維持原有授權與股數核對。

## 資金配置與成本

在歷史回放的「⚙ 模擬進階設定」選擇配置。新介面預設積極配置及逐筆可用分鐘行情；平衡配置和五分鐘排程可用於比較。配置僅套用本次虛擬帳戶，原帳戶設定保留。

| 參數 | 積極配置 | 平衡配置 |
|---|---|---|
| 單筆本金上限 | 權益 20%（十萬元為 20,000 元） | 權益 15% |
| 每日新增買進／筆數 | 權益 60%／8 筆 | 權益 40%／沿用設定 |
| 目標持倉 | 權益 70%，不強制買滿 | 權益 50% |
| 現金保留 | 權益 20% | 沿用設定，初始 25% |
| 單檔／總持倉上限 | 權益 25%／80% | 沿用設定，初始 20%／75% |
| 估計單筆停損風險 | 權益 1.25%，含買賣費稅 | 權益 1%，含買賣費稅 |
| 扣費報酬風險比 | 至少 1.2 | 至少 1.2 |
| 觀測股上限 | 16 檔，持倉持續監測 | 沿用設定，初始 12 檔 |

積極配置仍沿用日損失、行情新鮮度、商品資格與費率；跳空及未成交可能使實際損失超過估計。逐筆模式只使用資料中已存在的收盤價格事件，沒有插值、未來 K 棒或額外自動提高 Codex 呼叫上限；觸發更多交易可能增加股數確認呼叫。

「目前自訂風控」沿用儲存參數。舊版單筆 10%／現金保留 25% 的設定仍按扣除保留後計算，十萬元有效單筆上限為 7,500 元；在帳戶設定可明確切換計算基準。報酬風險比或單筆停損風險填 0 表示未啟用該檢查。變更實盤風控仍會停止既有自動交易授權。

綜合回測預設預估退出滑價與撮合滑價各 0.1%、3% 額外跳空壓力、2.5% 權益的壓力損失上限；正常單筆 1.25% 風險仍獨立保留。預估淨利至少 80 元，且至少為估計交易成本的兩倍。手續費率 0.1425%、最低 20 元及股票賣出稅 0.3% 為可設定假設；沒有擅自改成優惠最低費用。資金目標不強制買滿，沒有合格交易時保留現金。

需要公平比較時，在進階設定選「快速程式策略」並勾選同資料五組比較。五組是原始 v0.2.2 程式規則、僅進場、僅退場、僅配置及綜合；共同使用修正後的撮合與成本核對。這不是對原始 Codex 隨機輸出的逐筆重跑。

## 連線與停止

登入 Shioaji 後，行情、餘額、交割、持倉與委託分別核對；單項失敗保留最後成功資料，但資料不完整或價格過期時不送單。歷史模擬不讀取實盤銀行餘額及個人持倉。

Codex 中斷時查看「完整紀錄」的錯誤代碼；修復連線後按「測試連線」。歷史測試需要重新開始；日策略失敗時需重新分析。暫停買進、緊急停止與實盤限制保持原狀。

「停止交易」阻止新委託，既有券商掛單需另外處理；保留停損條件不保證網路中斷時能成交。Windows 發行者驗證需可信程式碼簽章；未配置憑證時會如實標記未簽章，詳見 [Windows 簽章](docs/WINDOWS_SIGNING.md)。
