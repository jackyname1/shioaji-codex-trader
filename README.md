# Shioaji Codex Trader

Shioaji 真實行情、Codex 策略、監測清單與持倉同時顯示的桌面交易工作台。內建券商連線，輸入 API Key 與 Secret Key 即可開始歷史模擬或實盤監控；實際下單時需要有效 CA。

![行情工作台](docs/screenshots/workbench.png)

## 功能

| 功能 | 說明 |
|---|---|
| API 與憑證 | 內建 Shioaji，輸入 API Key、Secret Key 即可連線；記住設定後，下次開啟自動連線。實盤下單需有效 CA。 |
| 模式工作台 | **模擬**集中日期、本金、回放時鐘與損益；**實盤**集中真實帳戶、五檔、委託和自動監控。Codex 常駐右側。 |
| 行情圖表 | 分鐘、5／15／60 分與日 K，即時五檔，搭配 MA5／20／60、波動帶、RSI、成交量、保護價格和模擬成交標記；可調整日期與時間軸。 |
| 歷史模擬 | 指定起訖日期、時刻和本金，終止時間最晚到現在；歷史行情分段下載、快取並保存，可匯出完整資料。 |
| 回放控制 | 暫停、繼續、單步與 1×～3000× 加速；最快估算模式可迅速跑完整個區間。 |
| 策略比較 | 快速程式策略或 Codex 逐輪分析；同一段資料可比較不同分析間隔，查看損益、資產曲線、回撤、費稅及成交紀錄。 |
| Codex | 在主視窗登入、選擇模型及推理強度、編輯指令，同時查看分析活動、資料時間與決策條件。 |
| 動態監測 | 自動更新 5–20 檔觀測股，顯示進場、停損、停利、移動停損與判斷原因；持倉及掛單持續保留監控。 |
| 交易管理 | 現股、盤中零股與整股限價單，委託／成交回報、可賣庫存、交割款、智慧保護、帳戶核對與撤單。 |
| 實盤啟動 | 主視窗按「啟動實盤」，一次確認完成本次授權與啟動；直接顯示待核對項目，不需輸入授權文字或設定環境變數。 |
| 桌面操作 | 深色工作台、專屬工作列與系統匣圖示、背景監控、暫停買進、緊急停止及本機紀錄保存。 |

實盤顯示截至現在的行情；模擬中的 AI、指標與觀測清單只使用截至當下模擬時間的資料。

## 開始使用

1. 下載 [v0.1.0 預發行版](https://github.com/jackyname1/shioaji-codex-trader/releases/tag/v0.1.0) 的 Windows 免安裝程式並開啟。
2. 按右上角「帳戶與設定」，輸入 API Key、Secret Key，再按「連線並核對」。要啟動實盤下單時，一起選取 CA 憑證並填入密碼。
3. 在主視窗選擇「模擬」，設定日期、本金與策略後開始測試；右側可直接設定 Codex、查看分析活動。
4. 選擇「實盤」即可查看帳戶與委託。完成 CA、費率與交割核對，儲存 Codex 設定並登入後，按「啟動實盤」確認一次即可開始。

授權只在本次程式執行期間有效；暫停／恢復不需重複確認。重新連線、重啟、緊急停止或變更交易風控後，需再次按「啟動實盤」。撤單可單獨授權，自動交易保持關閉。

## 開發

```bash
npm ci
npm test
npm start
npm run pack:win
```

需要 Node.js 24 以上；開發啟動與 Windows 打包時會取得並驗證官方 Shioaji。設定與報表保存在本機使用者資料目錄，無需固定自選股或 `config.yaml`。
