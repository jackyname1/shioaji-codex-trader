# v0.3.1 設定與工作台驗證

## Codex 用量

- 日常：09:15／11:45（Asia/Taipei），每日最多 2 次；啟動、手動分析、失敗嘗試及選用的股數模型共用該工作區額度。額度在呼叫前保存於工作區 SQLite，重啟不重置，以台北日期換日。到上限時下一次策略時間跳至後續交易日。
- 回測：獨立保存排程、固定時間、分析間隔、總上限、盤後檢討及股數確認方式。桌面預設每日 09:15、整次／整批最多 20 次；多組比較共享上限。回放倍速不改變分析排程。到上限後標為部分完成，不繼續新增策略；既有保護仍由程式監測。
- 兩者預設關閉額外盤後模型檢討、使用 deterministic sizing，數量不超過策略參考值；觸發後仍重新核對股數、資金、庫存與風控。可各自選回 Codex 額外確認。行情監測與持倉保護不依賴額外模型分析。
- 舊設定以 `codex_frequency_version` 做一次性升級，只調整日常用量預設；保留模型、推理程度、費率、資金與交易風控。後續使用者修改不被重套。

## 介面

主視窗左上及系統匣首區為持倉；主視窗右上直接編輯模型與推理強度，僅顯示最近 12 筆精簡執行紀錄，完整紀錄、輸入及回覆仍由既有歷史入口讀取。右下獨立策略表含個股決策、持倉保護與規則候選，可放大；未確定的規則價格／股數明確顯示待觸發／待核算，不捏造委託值。桌面移除時差診斷、時差提示及相關狀態投影，不改動登入簽章流程或系統時間。

## 測試與限制

本機 `npm test`：365 個測試，364 通過，1 個 Windows 專屬測試於 Linux 跳過，0 失敗。新增一次性升級、日常／回測設定隔離、每日額度失敗與重啟持久化、台北換日、預設排程、回測總額度測試。原本第二次 Codex 數量確認及盤後檢討測試均明確選用該模式，保留原有失敗與核對路徑的驗證。

Windows 原始程式與封裝 EXE 另由 PR CI 驗證，README 截圖及 `docs/screenshots/provenance.json` 連結至該次實際 Windows 隔離測試擷取的來源與圖檔雜湊。未使用券商憑證，未送出實盤委託；本次不主張策略獲利改善。
