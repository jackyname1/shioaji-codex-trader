# v0.1.1 — Pre-release

- 修正實盤未就緒原因被通用錯誤訊息掩蓋；CA、連線、行情串流、回報快取、帳務欄位與 HTTP 錯誤保留具體原因。
- 對齊 Shioaji Pro 1.7.7 的回報流程：重連先讀 trade_cache_health，只有 NotSubscribed 才訂閱；避免重複訂閱干擾保留的回報。回報遺失或快取不完整時重新核對，未知送單仍不重送。
- 券商 session 恢復期間暫停私人帳務查詢，保留最後成功餘額與持倉；恢復後重新核對。429 限流遵守 Retry-After，避免短週期重試持續加重限流。
- 新增「診斷」視窗：各端點狀態、最後成功時間、HTTP 錯誤、重試時間、服務與 CA 狀態。可匯出不含帳號、金鑰、憑證密碼及帳務內容的診斷 JSON。
- 參考 Windows 圖示指引與交易軟體的簡潔圖形，改為無字母的上揚 K 棒符號；視窗、工作列、系統匣及狀態圖示同步更新，16／24 像素採簡化輪廓。
- 新增可信 Windows 簽章流程，分別簽署本專案主程式與免安裝 EXE，保留官方 Shioaji／Codex 二進位檔。發行前核對真正的簽章、同一發行者、時間戳及下載檔雜湊，提供 WINDOWS-SIGNATURE.json。
- 設定產品發行者中繼資料；中繼資料不等於可信數位簽章。目前未配置程式碼簽署憑證時，版本明確標記為未簽章，SmartScreen 仍可能警告。設定 WINDOWS_SIGNING_REQUIRED 後，不會在簽章失敗時退回未簽章版本。
- 模擬保留即時／歷史回放，實盤保留即時流程。新增重連、回報遺失、限流恢復、具體錯誤與診斷隔離、簽章與發行者驗證的測試。

此版是新的 0.1.1 Release，保留先前的 0.1.0。CI 與 Windows 程式驗證使用隔離資料，不使用使用者的券商或 Codex 憑證。
