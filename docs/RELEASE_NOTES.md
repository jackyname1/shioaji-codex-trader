# v0.1.5 — 本機實盤紀錄恢復

- 修正 Windows 本機資料庫初始化的相容問題：使用使用者目錄 ACL，不對 SQLite 執行 Unix chmod。
- 舊資料庫鎖改用 Windows 唯讀程序查詢，避免以訊號探測要求程序終止權限；可確認已結束或 PID 重用的舊鎖會安全清理，擁有者不明時仍保留原紀錄與帳務唯讀。
- 修正鎖寫入失敗未關閉檔案，以及 SQLite 關閉後遇到暫時 unlink EPERM 使同一程式無法重試的問題。
- 診斷新增「重試本機紀錄」，直接重新開啟原資料庫並沿用已登入的 Shioaji；失敗時維持帳務讀取，成功後清除舊錯誤並保持自動交易關閉。
- 診斷會顯示失敗的本機步驟，不匯出私人路徑；同時修正診斷 JSON 匯出按鈕。系統匣與工作列同步顯示本機紀錄待修復。
- 修正 Windows 建置時官方 Shioaji 執行檔的解壓縮逾時，改用系統內建 ZIP 解壓工具並保留 SHA-256 驗證。
- 新增隔離的 EPERM、鎖清理、原紀錄保存、唯讀帳務、GUI 重試失敗及成功恢復驗證，測試不登入使用者帳戶、不送出實盤委託。

開啟修復版前，請先從舊版系統匣選擇「結束程式」。首次開啟會嘗試恢復原紀錄；仍顯示帳務唯讀時，可在「診斷」按「重試本機紀錄」。
