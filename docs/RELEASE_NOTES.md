# v0.2.1 — Pre-release

- 修正混合整股／零股持倉：與官方 Pro 一樣以 Share 單位讀取庫存，不再要求庫存明細才能顯示帳務；同日買進仍不可當沖賣出。
- 餘額、交割與持倉分別載入；單項失敗保留其他成功資料，顯示具體失敗端點並自動重試。
- 實盤連線後自動就緒，移除「啟動實盤」授權對話框；「開始自動交易」獨立控制 Codex 策略執行，重啟不恢復自動下單。
- 修正加密設定保存與狀態顯示；保存不受帳務／登入結果影響，更新 CA 或重新登入可留空沿用已保存金鑰。
- Codex 登入後自動測試目前模型，保留連線失敗原因；資料載入失敗不再只顯示「未通過」。停用分析器不需要的外掛同步；Windows 使用無需管理員初始化的受限執行環境。
- 歷史 K 線加入暫時性失敗重試、空快取重新取得與時間排序；查詢參數對齊官方 Pro。
- 每個版本建立獨立 Release；版本由 package.json 決定，已發布的版本、下載檔與 Git tag 保留不覆寫。
- 登入與設定一次，模擬、實盤共用 API/CA、帳戶選擇、Codex、排程與風控；舊版設定自動遷移。
- 修正已取得帳號卻顯示未連線：服務啟動等待健康狀態，行情登入與帳務核對分開，帳務失敗自動重試並顯示原因。
- 歷史模擬只使用行情端點，無需 CA、實盤餘額或委託回報；快速程式策略無需 Codex 登入。
- 移除手續費確認與交割符號設定；內建費用估計，未完成交割款保守預留，不提前使用未入帳收款。
- Codex 顯示實際登入狀態，開啟官方登入頁，提供重新開啟、裝置登入與模型連線測試；修正結構化輸出必填欄位。
- 歷史資料快取不再隨自動連接埠改變而重複下載；API 登入不會覆蓋未儲存的風控表單。
- 保留單一工作台的圖表、監測、持倉、成交與 Codex，直接切換模擬／實盤版面。
- 每筆實盤委託仍自動核對 CA、帳戶資料、行情時效與風控；停止或變更風控會立即關閉自動執行。
- 內建官方 Shioaji 1.7.7 與 Codex runtime，Windows x64 免安裝，無需設定執行檔、PATH 或服務網址。

開發與 CI 使用隔離行情、帳戶和登入程序，不使用使用者的券商或 Codex 憑證。
