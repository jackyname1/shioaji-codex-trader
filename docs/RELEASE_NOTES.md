# Shioaji Codex Trader v0.1.4

- 修正跨日保護觸發價誤用建立當日漲跌停的問題：停損等於或低於今日跌停不再僅因價格範圍遭拒；固定停利與估計收益目標也不以今日漲停截斷。它們是本機條件，觸發後才按當時行情產生合法委託。
- 統一策略與數量模型提示，要求以已完成資料支持目標與停損，不得為成本門檻任意提高目標或壓縮停損。單筆損失、隔夜跳空、成本、現金、集中度及實際委託當日漲跌停檢查持續執行。
- 補強無效或缺少進場保護的獨立檢查，涵蓋數量確認前與最終送單；新增跨日觸發、實際委託價限制與費後風控回歸測試。
- 舊報表載入與匯出時重新診斷觸發價誤擋，明確區分未平倉估值和已實現收益。原有報表與行情匯出入口保留。
- 這是邏輯與驗證修正，尚無使用者原始分鐘行情的修正版全期間績效，不宣稱已轉為獲利。重新驗證須保留費稅與成交假設，並使用未參與調整的期間；單一三個月反覆調參不構成樣本外證據。

提供 Windows x64 免安裝 EXE、SHA256SUMS、簽章報告與本版隔離測試畫面。
