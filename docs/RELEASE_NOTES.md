# Shioaji Codex Trader v0.1.0

此版本重新整理版本編號、設定及介面；保留本機資料與既有設定。舊版 GitHub Releases 在新版資產驗證完成後移除。

- 系統匣速覽順序改為基本資料、持倉、策略、監測及委託。
- 設定頁分成帳戶連線、日常排程、歷史回測、交易風控及進階與桌面，統一單位、有效範圍與儲存狀態。
- 歷史回測的獨立排程、分析間隔、整次／整批模型上限、股數核算及盤後檢討可直接在主設定頁修改並保存。
- 回測預設修改同步到下一次回測；一般設定更新保留尚未開始的回測草稿，既有報表與執行中設定不變。
- 補齊總持倉、每日買進、費稅、行情與帳務有效期、冷卻、候選池及 Codex 等待上限等常用設定。
- 股票策略總覽採一致的標題色條、固定表頭與精簡列表；右上保留可編輯模型、推理強度及簡要執行紀錄。
- 日常預設每日 09:15／11:45、每日最多 2 次；回測每日 09:15、整次／整批最多 20 次，皆預設程式核算股數、關閉額外檢討。
- 重整 README、操作說明及完整參數索引，更新本版 Windows 實際截圖與來源紀錄。

保留現金 25%、單筆可投資資金 10%、單檔 20%、總持倉 75%、每日新增 20%／5 筆與日損失 2% 的界線持續生效；更嚴格設定保留。未啟用實盤或研究選項。

Windows x64 免安裝；同頁提供 SHA256SUMS、簽章報告及隔離測試結果。測試使用合成帳戶與行情，不包含使用者金鑰、憑證或真實委託。
