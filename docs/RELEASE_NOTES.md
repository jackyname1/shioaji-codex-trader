# v0.1.0 — Pre-release

本次依要求重整版本為 0.1.0。新執行檔與下載檔驗證完成後，替換舊 0.1.0 並移除其他 Release；保留 Git 歷史。

- 修正回放與即時模式的股票排行方向：與官方 Shioaji Pro 一樣使用 `ascending=true` 取得高成交金額端，避免股票池全部落入低流動性股票而無法通過選股門檻。兩種模式共用相同掃描入口。
- 修正有效的 `HOLD_ONLY` 空候選被「至少 5 檔」誤判為策略啟用失敗。合格候選可為 0–20 檔；沒有合格股時保留現金，繼續後續排程與盤後檢討，既有持倉仍須有出場保護。
- 歷史選股優先使用官方 K 線 `Amount` 的實際新台幣成交金額；成交量由張換股一次，金額不重複換算。未提供完整成交金額時明確標記估算來源，舊行情快取自動更新。
- 快照補齊每日損失基準、可用現金、掛單占用、最低保留額、買進預算與股票價格限制。Codex 紀錄新增股票池、歷史就緒與基本資格數；每檔資料失敗原因保留，暫時失敗會再查詢。
- 保留三種工作台：模擬包含即時模擬與歷史回放，實盤使用即時行情；帳戶、圖表、條件與 Codex 紀錄跟隨目前模式。即時模擬使用獨立虛擬資金與正式行情，歷史模式不依賴實盤帳務。
- 每日固定時間或分析間隔執行快照、Codex 選股與買賣條件；短週期持續偵測與核對成交。條件觸發時另詢問 Codex 股數與限價，依最新現金、交割、掛單與庫存重新核對後送單。
- 持倉與未完成委託保留在監測清單；當日新增零股不可賣出，隔日依可賣庫存確認數量。模擬賣款到 T+2 才可再使用。
- Codex 股數確認不阻塞成交核對、暫停或緊急停止。停止、條件反轉、策略到期、設定或連線變更使舊建議作廢；HOLD 與拒絕結果冷卻後重試，未知委託不重送。
- 回放加速只縮短等待，每次選股、條件設定、股數確認、送單與成交核對均完整等待；可暫停、單步及直達下一觸發點。完整報表保存失敗原因、資料限制與委託過程。
- 整理重複股票與時間，同批官方行情修訂採最後一筆；CSV 相同紀錄合併，價格、成交量或成交金額衝突顯示具體股票與時間，不重複計算。
- 圖表支援滑鼠平移、游標錨定滾輪縮放、價格軸縮放、雙擊重設與鍵盤操作；底部時間軸同步，行情更新保留檢視位置。
- 重新設計無字母的軌道與四芒星圖示，套用至視窗、Windows 工作列與系統匣；待命、執行、暫停及離線有獨立狀態提示。
- 顯示官方目錄解析的實際 Codex 模型與推理強度；官方推理摘要、完整快照、原始 JSON、用量與送單結果可搜尋及匯出。活動更新保留展開內容與閱讀位置。
- 記住的 API Key、Secret Key 與 CA 密碼填回密碼欄位；未儲存輸入保留，清除記憶同步清空。秘密不包含在狀態輪詢、Codex 輸入與匯出紀錄中。
- 內建官方 Shioaji 1.7.7 與 Codex runtime，Windows x64 免安裝，不必設定執行檔、PATH 或服務網址。登入與設定一次，三種工作台共用。
- 實盤連線後自動就緒，開始自動交易獨立控制策略執行，重啟保持關閉；餘額、交割與持倉分別更新，載入失敗保留成功資料與具體原因並重試。
- 新增排行方向、官方成交金額、空候選完整回放、資料重試與版本重整測試；Windows 原始程式及打包執行檔另驗證三種模式、三種解析度、圖表操作、加密欄位、完整紀錄及原生圖示。

開發、CI 與執行檔驗證使用隔離行情、帳戶和登入程序，不使用使用者的券商或 Codex 憑證。
