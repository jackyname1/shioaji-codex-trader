# v0.1.2 — Pre-release

- 修正未建立工作台時無法登入與保存設定；登入先保存，再初始化工作台、驗證本機服務及載入資料。失敗後保留已保存設定，重試不需重開程式。
- 模擬委託不再阻擋重新連線或切換實盤；實盤未完成委託可用相同登入重新連線核對，換金鑰與切換模式仍會阻擋。
- 修正本機服務已登入卻工作台未就緒時仍顯示「Shioaji 已連線」；模式與狀態不再依賴成功建立的 runtime。
- 登入與設定錯誤直接顯示在視窗內，操作失敗也會刷新保存狀態，避免顯示「尚未保存設定」。
- 參考 Shioaji Pro，明確使用 --production 啟動真實行情；相同金鑰的健康自有服務可沿用，不反覆登入。CA 檔案不可讀時保留行情與帳務登入，實盤委託仍需有效 CA。
- 診斷涵蓋保存／啟動／工作台初始化與 /health、/info，工作台尚未建立時也能匯出安全原因。
- 修正工作台初始化失敗後未釋放資料庫，使同一個程式內的重試可成功。
- 加入完整首次登入 GUI 驗證：按下登入並記住、失敗後保存、視窗內錯誤、記住設定重試、模擬掛單切換實盤與無工作台重試。全部使用隔離資料，不登入使用者帳戶或送出實盤委託。

開啟新版前，請先從系統匣選擇「結束程式」；已有程式執行時，啟動另一個 EXE 會回到原來的視窗。

此版新增 0.1.2 Release，保留 0.1.0、0.1.1。可信簽章流程與 WINDOWS-SIGNATURE.json 保留；未設定可信程式碼簽章憑證時，發行檔仍明確標記為未簽章。
