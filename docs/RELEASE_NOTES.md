# Shioaji Codex Trader v0.1.1

- Codex 的策略／條件／掃描狀態與連線結果移到上方模型區，「測試連線」放在模型及推理選擇旁；實際模型與推理只顯示一次，連線結果只保留成功或錯誤訊息；下方集中顯示執行紀錄。
- 回測改以拉長分析間隔降低模型用量：預設每 5 個交易日於 09:15 分析，可在主設定與回測 ⚙ 調整為 1–20 個交易日。
- 休市不計，從回測起點後第一個可執行分析時刻起算；已知交易日即使缺行情仍計入，避免資料缺口改變排程。
- 非分析日持續處理行情、有效條件、委託及持倉保護，不會自動延長策略期限。額外盤後檢討只在分析日執行。
- 次數上限保留作預算保護；下一個必要模型步驟無剩餘預算時，停止並保存 PARTIAL 結果，不繼續模擬剩餘期間。沒有有效策略的測試仍標記 FAILED。
- 主設定與回測頁共用並保存跨日間隔，執行中沿用啟動時設定；結果與歷史紀錄顯示實際分析間隔。
- 舊 API 請求沒有跨日欄位時保留每日行為；已保存報表繼續可讀。本機資料、日常排程與交易風控不變。

每 5 個交易日分析時，一個月約需 4–5 次、三個月約需 12–13 次策略分析；額外檢討與股數模型另計。實際用量仍取決於快照大小、回覆與推理強度，不保證方案可用額度。

提供 Windows x64 免安裝 EXE、SHA256SUMS、簽章報告與本版隔離測試畫面。
