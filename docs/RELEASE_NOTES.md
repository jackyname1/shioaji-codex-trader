# Shioaji Codex Trader v0.1.5

- 修正策略當日到期造成跨日分析空窗的問題：新策略成功啟用後持續有效，直到下一份盤中策略成功驗證並啟用。收盤、跨日、模型回覆期限與下一輪排程均不會自動使已啟用策略失效；盤後檢討不替換盤中策略。
- 分離「模型回覆最晚可啟用時間」與「已啟用策略生命週期」，並同步引擎、重新啟動、自動啟動、數量確認與最終送單檢查。新策略驗證失敗不替換舊策略；故障暫停、用量上限、風控與自動交易權限仍生效。
- 工作台與系統匣顯示「持續有效 · 直到新策略成功接替」，移除容易混淆的策略期限設定。每日行情、交易資格、指標、帳務、費稅與風控仍重新核對；同一策略已執行訊號不重複買進，ROD 委託收盤取消與個別追蹤期限保留。
- 回測紀錄保存策略生命週期，診斷依實際替換時間計算覆蓋。回測快照的下一輪策略時間改為實際跨交易日排程；分析頻率與模型呼叫上限不變。
- 修正持續策略完全未成交的 ROD 收盤撤單後永久失去掛單機會：次交易日條件成立時重新核對及掛單；同日、部分／完全成交、送單不明及遭拒均不自動重送。包含跨日、重啟、部分成交及完整回測測試。
- 新增九項獨立成交帳務稽核，重算 FIFO 含買費成本、現金與待收款、庫存、費稅及淨值；新回測稽核失敗標為 FAILED。介面及 JSON／Markdown 匯出顯示核對結果、期末估計賣出費稅後淨損益、陳舊估值警示與績效驗證狀態。正報酬、小樣本與合成測試不宣稱可實盤。
- 舊版保存的策略與回測保留原期限與原始結果；更新後重新分析可建立持續策略，回測需重跑才會反映修正。新增跨日觸發、六交易日替換、重啟保存、失敗替換、盤後檢討及舊版期限相容測試；Windows 來源與封裝版驗證持續策略介面。

此版本修正策略生命週期並加強回測核對，尚未以使用者原始分鐘行情驗證修正後的三個月收益，不宣稱已獲利。提供 Windows x64 免安裝 EXE、SHA256SUMS、簽章報告與本版隔離測試畫面。
