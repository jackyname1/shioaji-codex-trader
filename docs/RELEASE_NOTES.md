# v0.4.0 Windows 測試版

下載 `Shioaji-Codex-Trader-0.4.0-Windows-x64.exe`，開啟即可測試。DEMO 不需要安裝 Node.js 或登入券商、Codex。應用程式與交易引擎全部使用 TypeScript，直接連接官方 Shioaji HTTP／SSE。

## 這次重做的功能

- 參考 Shioaji Pro 的操作流程，重新設計原創四頁文字介面：「總覽」「策略與觀測」「模擬」「設定」。關閉或最小化縮到系統匣，點圖示重開。
- 三個節奏獨立設定：預設台北時間 09:15、11:45 由 Codex 決定策略，程式每 3 秒偵測條件、每 5 分鐘更新觀測股；也可改成較長策略間隔。排程持久化，重啟不重複執行同一時段，過久的錯過排程不補跑。
- Codex 可授權有界限的趨勢、突破或回檔進場條件，包含成交金額、量比、RSI、部位比例及停損／停利／移動停損。程式在兩次策略決策之間持續檢查，符合條件才送單。
- 自動選入、增補及刪除觀測股，預設最多 12 檔、前一完整交易日成交金額至少 NT$20,000,000。不合格即停止買進並撤掉買進餘量，連續 3 次未通過再移除；持倉與未完成委託保留保護監控。新一輪 Codex 優先股可替換舊觀測股。
- 零股 1–999 股優先；整股可選 1000 股倍數，使用獨立整股行情判斷，保護出場含零股餘數。禁止賣出當日新取得股數。部分成交、撤單確認、未知結果與冪等委託持續核對，不盲目重送。
- 原生 SSE 行情與回報快取支援短間隔偵測；送單前及異常時強制核對券商。專用服務會輪替本程式行情訂閱；與 Pro 共用時可關閉訂閱管理，累積達 160 個便停止新增並顯示原因。

## 立即測試歷史模擬

1. 打開「模擬」，設定日期區間與起始資金，保留虛構行情及流程示範。按「開始全自動模擬」，免登入即可驗證流程。
2. 使用固定時間，或切換策略間隔；偵測秒數與觀測刷新分鐘數各自調整。程式沿實際提供的行情事件重播，沒有行情的間隔不虛構價格。
3. 按「自動比較間隔」可依序比較 60／120／180 分鐘等設定，使用相同資料及起始資金、獨立持倉與經驗記錄。Codex 呼叫上限為整批共享，包含盤後檢討。
4. 查看淨損益、已實現／未實現、費稅、FIFO 成本、T+2 賣款資金限制、最大回撤、逐日資產、觀測增刪及策略記錄。最近 30 次結果可切換，原始檔仍保留；匯出完整 JSON 與成交 CSV。
5. 要驗證整股，勾允許整股並提高資金，例如 NT$1,000,000；仍須符合單筆、部位與曝險上限。

也支援匯入歷史 CSV 或從官方本機服務唯讀取得分鐘 K 線，並由真正 Codex 在每個虛擬策略時段決策。缺漏交易日、分析失敗、呼叫預算耗盡或取消會明確標示部分／失敗結果。至少需要 20 個先前交易日暖機；日 K 不支援精確盤中固定時刻排程。

## 使用 Codex 與真實交易

在「設定」啟動內含的官方 Codex 登入，於自己的電腦完成認證；勾選定時策略並設定時間。接著依 README 設定官方本機 Shioaji 服務，先使用 READONLY／PAPER 核對帳戶、行情與可賣庫存，再於本機完成 LIVE 授權。預設沒有啟用實盤或自動委託。

模型決策必須通過獨立風控。經驗記錄會回饋成交、拒絕與檢討，供後續分析參考；不會自動訓練模型權重、修改程式或放寬風控。實盤缺少實際成交價及費用時，只記錄已核對股數。

分鐘 K 線無法還原零股五檔、排隊及精確撮合，稀疏行情也不能證明每秒策略表現。報表會列出估計價差、資料池、企業行動及模型歷史知識等限制。`SYNTHETIC-*` 附件與介面截圖均為虛構行情的流程測試，不代表投資績效。

本版支援標準官方 HTTP 服務；啟用 Agent Harness 的服務仍需整合官方可信任能力票證，本版會拒絕真實委託。EXE 尚未簽章。券商登入、CA、實際成交及使用者 Codex 認證需在本機驗證。

Release 僅在 Linux／Windows 自動測試、實際 Electron 四頁介面檢查，以及打包 EXE 啟動與回測檢查全部成功後發布。`SHA256SUMS.txt` 提供附件校驗碼，README 包含完整操作與設定。
