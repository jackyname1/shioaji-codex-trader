# v0.2.3 — Pre-release

- 新增即時模擬，使用正式市場行情與獨立虛擬帳戶；主視窗可切換即時模擬、歷史回放與實盤，帳戶、圖表、條件及 Codex 紀錄跟隨目前模式。
- 統一兩段交易流程：每日固定時間／間隔建立快照、Codex 選股與買賣條件；短週期持續偵測、核對成交。觸發時另詢問 Codex 實際股數與限價，再依最新現金、掛單預留、交割與庫存重新核對後送單。
- 持倉與未完成委託立即保留在監測清單；未受保護的持倉若缺少 Codex 出場條件，新策略不會啟用。當日新增零股不可賣出，隔日才依可賣庫存確認數量。
- Codex 數量等待不占用監控佇列；成交核對、暫停與緊急停止持續可用。停止、條件反轉、策略到期、設定或連線變更會使舊數量建議作廢。HOLD 與拒絕結果採冷卻重試，未知委託不重送。
- 歷史回放也完整等待每次數量確認，不跳過步驟；呼叫預算包含選股、股數確認及檢討。即時模擬與回測的賣款均到 T+2 才可再使用。
- 模型留空時透過官方 model/list 解析實際預設模型並明確指定，顯示模型及推理強度。官方推理摘要、快照、完整 JSON、用量、策略與送單結果保存，可搜尋、查看完整紀錄與匯出；畫面只載入近期活動，完整快照按需載入。
- 記住的 API Key、Secret Key 與 CA 密碼會自動填回密碼欄位；未儲存輸入保留，清除記憶同步清空欄位。秘密不放進狀態輪詢、Codex 輸入或交易紀錄。
- 重新設計工作列與系統匣圖示，增加待命、執行、暫停和離線狀態；系統匣及 Windows 工作列同步顯示狀態。
- 新增股數確認、現金變更、條件失效、緊急停止、未知送單、零股隔日出場、模型目錄、完整紀錄及回放等待測試；Windows 原始與打包程式驗證三種工作台、三種解析度、圖表操作、加密欄位與完整紀錄。

# v0.2.2 — Pre-release

- 圖表加入滑鼠拖曳平移、游標錨定滾輪縮放、價格軸拖曳縮放、雙擊重設及鍵盤操作；底部時間軸與圖表同步，行情更新保留檢視位置，「最新」可恢復跟隨。
- 整理歷史資料的重複股票／時間與重複排行股票；同批 Shioaji 行情修訂採最後一筆，成交量不重複計入。CSV 相同資料自動合併，衝突資料顯示股票與時間供核對。
- 預設使用 Codex 每日選股；依歷史時間建立快照、分析選股、設定條件，再由同一交易引擎偵測、風控、模擬送單與核對成交。每步等待完成後才推進時間。
- 快進只縮短事件等待，不跳過 Codex、策略啟用、委託或核對；暫停／單步保留未執行事件，策略到期也會在 K 線之間觸發。
- 新增當前步驟、下一觸發時間、每日選股門檻、委託與成交流程報表；模擬成交隨時間更新，分析失敗保留具體原因並允許後續交易日恢復。
- 執行中鎖定本輪模擬參數，防止畫面與實際排程不同；減少長期報表與成交明細的畫面傳輸量，完整資料仍保存並可匯出。
- 新增重複行情、延遲 Codex、快進等價、逐步執行、到期撤單及跨日恢復測試；Windows 桌面與打包程式另驗證實際滑鼠縮放、平移、價格軸、時間軸及三種解析度。

# v0.2.1 — Pre-release

- 修正混合整股／零股持倉：與官方 Pro 一樣以 Share 單位讀取庫存，不再要求庫存明細才能顯示帳務；同日買進仍不可當沖賣出。
- 餘額、交割與持倉分別載入；單項失敗保留其他成功資料，顯示具體失敗端點並自動重試。
- 實盤連線後自動就緒，移除「啟動實盤」授權對話框；「開始自動交易」獨立控制 Codex 策略執行，重啟不恢復自動下單。
- 修正加密設定保存與狀態顯示；保存不受帳務／登入結果影響，更新 CA 或重新登入可留空沿用已保存金鑰。
- Codex 登入後自動測試目前模型，保留連線失敗原因；資料載入失敗不再只顯示「未通過」。停用分析器不需要的外掛同步；Windows 使用無需管理員初始化的受限執行環境。
- 歷史 K 線加入暫時性失敗重試、空快取重新取得與時間排序；查詢參數對齊官方 Pro。
- 每個版本建立獨立 Release；版本由 package.json 決定，已發布的版本、下載檔與 Git tag 保留不覆寫。
- 登入與設定一次，模擬、實盤共用 API/CA、帳戶選擇、Codex、排程與風控；舊版設定自動遷移。
- 修正已取得帳號卻顯示未連線：服務啟動等待健康狀態，行情登入與帳務核對分開，帳務失敗自動重試並顯示原因。
- 歷史模擬只使用行情端點，無需 CA、實盤餘額或委託回報；快速程式策略無需 Codex 登入。
- 移除手續費確認與交割符號設定；內建費用估計，未完成交割款保守預留，不提前使用未入帳收款。
- Codex 顯示實際登入狀態，開啟官方登入頁，提供重新開啟、裝置登入與模型連線測試；修正結構化輸出必填欄位。
- 歷史資料快取不再隨自動連接埠改變而重複下載；API 登入不會覆蓋未儲存的風控表單。
- 保留單一工作台的圖表、監測、持倉、成交與 Codex，直接切換模擬／實盤版面。
- 每筆實盤委託仍自動核對 CA、帳戶資料、行情時效與風控；停止或變更風控會立即關閉自動執行。
- 內建官方 Shioaji 1.7.7 與 Codex runtime，Windows x64 免安裝，無需設定執行檔、PATH 或服務網址。

開發與 CI 使用隔離行情、帳戶和登入程序，不使用使用者的券商或 Codex 憑證。
