# v0.1.0 — Pre-release

- 主視窗「啟動實盤」只需一次確認，完成本次授權與啟動；移除授權文字及環境變數要求。
- 直接切換實盤帳戶監控，CA 僅於下單啟動時核對；未就緒項目與授權狀態常駐顯示。
- 授權只綁定本次連線帳戶；重啟、重新連線、緊急停止或變更交易風控後自動關閉。單獨撤單不開放新委託。
- 修正自動更換連接埠時誤判帳戶、啟動／停止交錯及帳戶操作衝突。
- 補齊撤單期間新增成交的紀錄；已取消分析不會再啟用排隊結果。
- 修正快速換股票漏載圖表、歷史報表圖表日期及 Codex 儲存覆蓋未儲存帳戶修改。
- 內建 Shioaji 1.7.7，行情登入只需 API Key、Secret Key；實盤下單需有效 CA 憑證。
- 自動管理連線與連接埠，記住設定後下次啟動自動連線。
- 單一視窗同時查看行情、監測、持倉、成交與 Codex，不再切換五個頁面。
- 模擬／實盤直接切換工作台；右側 Codex 與左側監測持倉保持常駐。
- 模擬的圖表、持倉、監測清單、策略與分析活動使用同一個歷史時間。
- 1366 × 768、1600 × 960 與 1920 × 1080 版面驗證；帳戶和進階設定以視窗開啟。
- 保留歷史資料匯出、速度控制、策略比較、模型與推理強度、智慧保護及風控。
