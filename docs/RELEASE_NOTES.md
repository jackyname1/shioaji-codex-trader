# Shioaji Codex Trader v0.1.2

- 新增「資產與損益 → 匯出回測紀錄」，集中完整 JSON、成交 CSV、完整交易 CSV、每日淨值 CSV 與損益診斷 Markdown。
- 完整 JSON 保留本次版本、來源提交、設定、策略、委託、成交、每日資產與 Codex 紀錄；診斷拆分費用前後損益、平倉勝率、平均損益、出場原因與策略期限空窗。成交 CSV 補上成交／委託 ID、出場原因及五檔來源。
- 修正組合研究風控關閉時平倉筆數總是 0 的問題；統計與開關分開，完整取得同一測試、截至當下的模擬成交，不受提示經驗上限影響。未啟用的研究風控保持關閉。
- 回測完成與舊報表載入時產生診斷；執行中禁止匯出尚未完成的結果。儲存對話框固定匯出選取時的報表，避免切換報表混淆。
- 保留每 5 個交易日分析及策略到期規則；報告明列無有效策略日，不偷偷延長期限、增加模型用量或放寬交易風控。
- 加入匯出資料核對、期限覆蓋、研究開關關閉時的完整交易統計，以及來源／封裝 Windows GUI 的五種匯出與取消驗證。

本版修正可驗證的統計與匯出問題，沒有以單一虧損期間調參，也沒有宣稱三個月回測已轉正。只持有 Codex 執行紀錄無法重建完整分鐘行情；重跑時請同時保存完整回測 JSON 與行情資料。

提供 Windows x64 免安裝 EXE、SHA256SUMS、簽章報告與本版隔離測試畫面。
