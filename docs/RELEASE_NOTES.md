# Shioaji Codex Trader v0.1.6

這是回測正確性、研究工具與正式交易停用保障的預發行版，**沒有宣稱策略已具扣費正期望值，也不能啟用正式下單**。

- 策略回覆期限由程式依單一快照建立，區分明示時區、無效時間、已過期與超過本機窗口等錯誤碼。保留 `UNTIL_REPLACED`；明確無效的新提案不覆蓋有效策略及持倉保護。新策略先成功持久化，再清理舊進場委託；提交後清理失敗明確封鎖新進場。
- 修正舊零設定停用單筆風險與成本檢查：至少保留現金 25%，單筆本金 10% AFTER_RESERVE，單檔 20%、總曝險 75%、每日新增 20%／最多 5 筆、日損失 2%、單筆含成本停損風險最多 1%。更嚴格設定保留；限價買進、無槓桿及禁止當沖的規則不變。
- 部分成交的剩餘本金與增量費用使用同一個精確計算核心，回測、工作台及系統匣不再重複保留已支付的最低手續費。
- 完整交易勝率、PF 與期望值由原始成交及 FIFO 成本重算；新增當時報價、費稅、報價差及模型價格影響歸因。缺少舊報價時維持未知，不補造滑價或選股／市場因果。
- 真正八階段唯一訊號漏斗：候選、資料、趨勢、觸發、成本、風控、送單、成交。重複掃描不增算機會，未觀測與無此要求分開；觀測異動增加完整 SQLite 事件帳。
- 期末估值過期、隔夜持倉遇未處理公司行動權益、缺行情與診斷截斷均保留不完整原因、日期、階段及錯誤碼。增加 2023/08/03 官方颱風停市證據及可見性／T+2 回歸。
- 結果頁顯示回撤、累積費稅、曝險、完整交易歸因與漏斗；提供 12 種 JSON／CSV／Markdown 匯出。Windows 來源及封裝 GUI 皆實際驗證入口、內容與帳務數字。
- 新報表保存完整有效設定及資料內容 SHA256；新增不可補修舊回覆的固定決策重播，以及固定 ablation、三種成交情境、較長歷史與參數敏感度研究工具。保存零成交與失敗方案，不自動部署研究設定。
- 移除模式切換及故障恢復的自動實盤授權。由於缺少獨立 OOS、足量穩健正期望值與 Shadow 證據，正式下單以 `LIVE_VALIDATION_PENDING` 停用；明確撤單仍須原帳戶／CA／核對條件，不授予新委託權限。

原始 v0.1.5 的兩份紀錄與同次分鐘行情尚未在執行環境取得，原始 14 筆交易核對、9/9 完整根因及原始 AI 策略重跑仍未結案。公開日線程式策略比較不能冒充原始 AI 結果；2026/07/22–10/22 與已研究面板不能改稱全新樣本外。

需要 Node.js 24 以上。所有使用者資料、憑證、金鑰及帳務均不進入版本庫；更新保留本機資料。發行資產與 SHA-256 以版本頁的實際核對結果為準。
