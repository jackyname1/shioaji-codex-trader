# Shioaji Codex Trader v0.1.3

- 修正「測試紀錄 → 檢視」後找不到匯出入口的問題：報表視窗上方直接提供「匯出完整 JSON」「其他匯出格式」「匯出行情資料」，不需返回被視窗遮住的主畫面。
- 匯出區固定在報表上方，捲動長報表仍可操作；顯示目前選取的日期與狀態。沒有報表、執行中或舊報表缺少行情時，顯示具體原因。
- 切換報表載入期間暫停匯出，避免拿到上一份結果；可從原報表視窗開啟其他格式，關閉後繼續檢視。
- Windows 來源與封裝 GUI 驗證實際點選「檢視 → 匯出完整 JSON／行情資料」，核對所選報表 ID、行情筆數及捲動後按鈕可見；保存本版報表畫面與來源雜湊。

提供 Windows x64 免安裝 EXE、SHA256SUMS、簽章報告與本版隔離測試畫面。
