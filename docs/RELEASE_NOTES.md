# v0.3.0 Windows 測試版

下載 `Shioaji-Codex-Trader-0.3.0-Windows-x64.exe`，開啟即可測試；不必為 DEMO 安裝 Node.js、登入券商或登入 Codex。

## 立即測試

1. 展開「日期區間歷史模擬／損益報表」，設定開始日、結束日及起始資金。
2. 保留「虛構行情（免登入）」及「流程示範（非 Codex）」，按「開始全自動模擬」。
3. 查看損益、手續費、交易稅、最大回撤及逐日資產。可匯出完整 JSON 和成交 CSV。
4. 測試整股時勾「允許整股」，提高起始資金，例如 NT$1,000,000，讓 1000 股委託能通過單筆上限。
5. 最小化或關閉視窗會縮至系統匣；點圖示重開，選「結束程式」才會停止。

## 功能

- 零股 1–999 股、可選整股 1000 股倍數、整股保護出場及零股餘數處理。
- 定時 Codex 選股、智慧單數值分析；常駐引擎監控停損、停利、移動停損、部分成交、資金及委託。
- 指定日期區間的自動歷史重播，可匯入 CSV 或從官方 Shioaji 服務唯讀取得歷史分鐘 K 線。
- 真正 Codex 歷史決策模式：每個虛擬交易時段呼叫官方 SDK，盤後檢討；可限制呼叫數、取消及保存部分結果。
- 費稅、FIFO 已實現成本、未實現損益、T+2 賣款資金限制、最大回撤及完整逐筆報表。
- 經驗回饋保存成交／拒絕／檢討，供後續分析參考；不同交易模式與每次回測隔離，禁止讀取虛擬日期之後的結果。
- 內含官方 Codex 執行檔，可由「Codex 登入與經驗回饋」啟動瀏覽器登入。

## 使用真實資料及交易

DEMO 預設開啟，實盤及自動委託預設關閉。請依隨附 README 設定官方 Shioaji 本機服務，先用 READONLY/PAPER 核對帳戶；在本機完成 Codex 登入與啟用定時分析，再完成實盤授權。

模型產出仍受獨立風控檢查。經驗回饋是記錄與提示詞回饋，沒有自動重新訓練模型、修改程式或放寬風控。實盤未取得實際成交價及費用時，只記錄核對股數，不杜撰實盤損益。

歷史分鐘 K 線不能完整還原零股五檔及撮合；日 K 不能還原盤中停損。報表會列出估計深度、價差、資料池、企業行動及模型歷史知識等限制。示範報表全部為虛構資料，不是 Codex 的真實投資績效。

本版支援標準官方 HTTP 服務；若服務啟用 Agent Harness，本版會拒絕真實委託，仍需另行整合官方可信任能力票證。Windows EXE 尚未簽章。券商登入、CA、實際成交與 Codex 認證不在 CI 驗證範圍。

Release 只在 Linux／Windows 測試、Windows 文字介面測試及打包 EXE 啟動與回測檢查全部成功後發布。

`SHA256SUMS.txt` 提供各附件的 SHA-256；README 包含完整設定、風控及操作說明。
