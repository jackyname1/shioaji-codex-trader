# v0.1.3 — Pre-release

- 全面更新深色配色：石墨黑背景，紫色主要操作、冰藍行情、薄荷綠即時流程、暖金色歷史回放；各區塊的標題與狀態更容易辨識。
- 提高輔助文字、表格與圖表座標的對比；設定視窗、保存狀態、錯誤提示及捲軸同步使用新色系。
- K 線、均線、成交量、資產曲線與停損停利線共用介面配色；漲跌維持台股紅漲綠跌。
- 應用程式、Windows 工作列與系統匣圖示同步更新為紫色漸層底、金色／冰藍／紫色三根 K 線的符號，沒有字母。正常、執行中、暫停與離線保留可辨識的狀態色。

開啟新版前，請先從系統匣選擇「結束程式」；已有程式執行時，啟動另一個 EXE 會回到原來的視窗。

此版新增 0.1.3 Release，保留先前版本。未設定可信程式碼簽章憑證時，發行檔仍明確標記為未簽章，實際狀態見 WINDOWS-SIGNATURE.json。
