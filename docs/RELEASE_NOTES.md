# v0.1.5 — 本機實盤紀錄恢復

- 修正 Windows 本機資料庫初始化的相容問題：使用使用者目錄 ACL，不對 SQLite 執行 Unix chmod。
- 舊資料庫鎖改用 Windows 唯讀程序查詢，避免以訊號探測要求程序終止權限；可確認已結束或 PID 重用的舊鎖會安全清理，擁有者不明時仍保留原紀錄與帳務唯讀。
- 修正鎖寫入失敗未關閉檔案，以及 SQLite 關閉後遇到暫時 unlink EPERM 使同一程式無法重試的問題。
- 診斷新增「重試本機紀錄」，直接重新開啟原資料庫並沿用已登入的 Shioaji；失敗時維持帳務讀取，成功後清除舊錯誤並保持自動交易關閉。
- 診斷會顯示失敗的本機步驟，不匯出私人路徑；同時修正診斷 JSON 匯出按鈕。系統匣與工作列同步顯示本機紀錄待修復。
- 修正 Windows 建置時官方 Shioaji 執行檔的解壓縮逾時，改用系統內建 ZIP 解壓工具並保留 SHA-256 驗證。
- 新增隔離的 EPERM、鎖清理、原紀錄保存、唯讀帳務、GUI 重試失敗及成功恢復驗證，測試不登入使用者帳戶、不送出實盤委託。

開啟修復版前，請先從舊版系統匣選擇「結束程式」。首次開啟會嘗試恢復原紀錄；仍顯示帳務唯讀時，可在「診斷」按「重試本機紀錄」。

# v0.1.4 — Pre-release

- 還原原先深藍黑色背景；桌面、工作列及系統匣圖示改用深色底，保留無字母的彩色 K 線符號。
- 對照 Shioaji Pro 的帳務呼叫：明確指定證券帳戶，庫存使用 Share 股數，登入共用同一個本機服務。
- 修正舊唯讀實盤紀錄切換正式模式的相容問題，保留帳戶識別、委託與成交歷史；不會把模擬委託轉成實盘委託。
- 本機資料庫或舊策略紀錄無法載入時，保留原紀錄，仍可讀取券商帳務；此時停用實盤委託，直到原紀錄恢復可核對。桌面偏好保存失敗也不會阻止已登入的帳務讀取。
- 連線診斷加入工作台階段與安全錯誤代碼，區分資料庫、保存偏好及 API 讀取；不再把本機初始化失敗一律顯示為 Shioaji 連線失敗，也修正重複的錯誤文字。
- 修正初始化失敗未關閉 SQLite 與重複關閉的問題，允許安全重試；成功恢復 API 後清除過時的啟動錯誤。
- 新增真正的本機 HTTP 相容測試、舊實盤歷史、損壞資料庫、保存失敗與 Windows 介面操作檢查；全部使用隔離資料，不登入使用者帳戶或送出實盤委託。

開啟新版前，請先從系統匣選擇「結束程式」；已有程式執行時，啟動另一個 EXE 會回到原來的視窗。

新增 0.1.4 Release，保留先前版本。未配置可信程式碼簽章憑證時，發行檔仍標記為未簽章，見 WINDOWS-SIGNATURE.json。
