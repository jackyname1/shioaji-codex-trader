# 0.3.0：執行可靠性與確認策略驗證

此版本修復確定性保護被模型錯誤阻擋的問題，加入可選程式 sizing、獨立確認策略、成交敏感度及可重現比較。沒有啟用實盤或使用真實帳戶送單。確認策略、提示壓縮及既有研究選項僅供模擬／回放；無法據此宣稱已證明正期望值。

## 核心修正

- 持倉保護直接使用已核對可賣量，模型故障不會阻斷它。緊急停止、實盤交易授權、帳務／行情新鮮度、合法股數／價格、委託去重與券商核對仍適用。
- 程式 sizing 使用策略參考股數作上限，向下取合法交易單位；小額成本不合格時觀望，不能為達門檻向上加股或提高目標。每次保存完整 sizing 快照及決定，最後再次驗證。明確不合格的確認訊號、廣度、同股加碼及跌停停損在股數模型前拒絕；模型提示依所選 sizing 模式說明權限，已有保護的 HOLD 不需捏造新收益目標。
- 舊 Codex sizing 仍可明確選擇；舊版參考股數本來就不是數量上限，模型可以在硬性預算內增加，因此參考與送單差異不等於算術錯誤。
- 確認策略採完整均線順序、MA20 上升、站回 MA5、距離 MA20 不超過2 ATR；反彈需已觀測低點後的 REBOUND，突破需前一已完成交易日量比及既有壓力。前日量能不是當日盤中量能確認。
- 確認策略禁止同股加碼，賣出後等待兩個完整交易日；池內有效股票不足五檔或廣度代理偏弱時不買。此廣度不是加權指數。
- 確認策略含持倉／掛單的產業曝險30%、組合同時停損估計2%。未知產業視為與所有產業完全相關；缺少持倉保護則拒絕新增。未知掛單風險按全額本金保留。跳空及無買盤可超過名目風險，另保留既有隔夜跳空檢查。
- 所有策略新增買進均拒絕停損位於或低於已確認跌停價。不能將跌停視為保證成交的退出價。
- 結構化錯誤區分 JSON／結構／語意，僅記錄安全欄位路徑及代碼；無效輸出不轉成可執行提案。
- 多個 HTTPS Date 來源進行唯讀粗略時差檢查；不足或不一致顯示未知。未使用本機 health timestamp 作券商時間、未修改 Windows、未放寬簽章時效。CLI：`node dist/src/cli.js --clock-check`。

## 可重現比較

先建置目前版本及獨立 v0.2.9 checkout，然後：

```bash
node scripts/compare-v030.mjs /absolute/path/to/v029 /private/results/comparison.json
python scripts/audit-execution-history.py /private/history.json --output /private/audit
node scripts/revalidate-v030-history.mjs /private/history.json /private/revalidation.json
npm test
python tests/audit-history.test.py
```

協定：[protocol.json](../validation/v030/protocol.json)。基準固定 `db608ac3395c76da9e5170014d427a2acc1090ed`；讀取其完整舊引擎，並在兩版外部套用完全相同的成交情境。一般成交量估計在整股／零股間分攤，不各複製全額。保存資料、協定、兩版引擎及每個完整報告的 SHA-256。

比較包含原引擎／現版原策略／三個確認策略、三個時間區段及三種成交假設，共45組。基準為現金及75%本金等權買入持有，整數股、價差及最低費用均計入，期末庫存採市值，不假設已賣出。每組從相同本金、零庫存重啟；沒有參數搜尋或模型呼叫。

這是公開十檔固定池日K的程式策略比較，**不是原始 Codex 動態股票池的完整重跑**。原匯出不足以重建每分鐘路徑、未入選股票及真實零股深度。原帳戶路徑的拒絕／通過檢查不能當成新的投組收益；不得挑出留下的獲利交易相加。

時間切分含較早季度、診斷月份及後續時段；該公開資料過去已在專案研究中使用，不標示為完全未觸碰過的樣本外資料。短樣本不年化。固定股票池仍有選取／存活偏誤；未經調整的價格不是含息總報酬。

## 成交情境與限制

| 情境 | APPROXIMATE 深度 | 額外價差 | 日K盤中推估 |
|---|---:|---:|---|
| 較樂觀 | 基礎估計100% | 無 | 使用前日量假設 |
| 中性 | 基礎估計10% | 每邊1 tick | 使用前日量假設 |
| 保守 | 基礎估計1% | 每邊2 ticks | 不推估盤中成交 |

基礎深度仍是一般成交量乘參與比，非零股歷史佇列。整股五檔不會標成已觀測零股五檔。保守日K零成交不能當成有效 alpha；價差改變會改變進出路徑，收益不一定隨情境單調排序。所有情境保留延後成交、有限量、部分成交、取消／重掛、FIFO、最低手續費、賣出稅及交割日曆。缺乏券商真實費率時20元只是目前設定。

## 模型成本

規則、價格、股數、成本及風控由程式計算。列式提示保留數值、帳務、行情及限制；可選壓縮另截短歷史備註，完整事件仍保留。以同份快照計算 UTF-8 bytes，與實際輸入 tokens 分開。移除已記錄 sizing 呼叫的機械用量可精算；新提示的付費 tokens、錯誤率與決策效果在沒有配對模型執行前一律為 NOT_RUN。
