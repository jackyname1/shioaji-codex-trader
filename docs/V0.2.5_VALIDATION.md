# 0.2.5 安全修正與研究驗證

本版先修復可重現的程式與風控問題。研究功能預設關閉；沒有實際下單、修改 API 金鑰、調整券商授權或啟用 LIVE_TRADING。

## 版本與授權

基準為不可變 v0.2.4 提交 `787a7af454143b2f3f49a7cbdb2c6b658189fd96`。舊匯出只含 app version，不含建置提交，因此僅憑匯出不能證明二進位來源。本版匯出增加 source commit/tree/dirty 狀態；來源封裝缺 git 時明確回報 unknown。

歷史變更可由 `git log -- src/core/capital.ts src/core/models.ts` 還原：0.2.0 引入 balanced（單筆權益15%、日40%），0.2.2 引入 active（單筆20%、日60%／8筆、現金20%、單檔25%、曝險80%）。這些原本限回放，但不能視為使用者授權放寬。查得原始使用者限制為現金25%、單筆可投資資金10%、單檔20%、持倉75%、日新增20%／5筆、日損失2%；未找到明確放寬上述額度的使用者指示。本次指示明確要求在無授權時恢復，因此程式現在對所有模式強制該上限，保留更嚴格值。

## 確認的缺陷與修正

- 同檔加碼的 entryRiskIssues 原本只估新增股數。現在依已持有成本、新買費用及合併賣出費稅計算同檔停損風險，另合併隔夜壓力風險。股數確認、股數上限搜尋和最終送單前都重新核對。
- 回放活動轉成匯出 analyst events 時丟失 order_id/trigger/state。現在保留完整成交／委託物件，保護單記錄實際觸發 quote 與有效停損價，避免日後只能用文字猜測。
- 回測報告版本仍寫死 0.2.3。修正為本版並同步報告還原驗證；GUI 匯出另帶建置來源。
- 原回放可能在未提供真實零股五檔時假設漲跌停雙向皆有深度。近似行情在封漲停不假設買得到、封跌停不假設賣得出；未知公司行動、停牌及無法解釋的超幅價差不產生可成交報價。模擬撮合拒絕未來／過期、倒置及不合法 tick 報價。
- 交割行事曆改以已知截止時間檢查臨時休市；賣出後才公告的休市會延後款項可用時間，缺交割日曆時不跳過未知平日。新賣款保存出售日，補足行事曆後才能重新核對。
- 原單檔上限只檢查本次委託股票；舊有另一檔持倉或其掛單已超額時仍可能新增風險。現在逐一檢查全部持倉及掛單集中度，超額先阻擋新買進，不強制賣出或繞過可賣股數。
- 標準回放配置保留既存較高淨報酬風險門檻、較低停損預算及較低軟性持倉目標。不得因選擇舊配置名稱而放寬這些限制；本次比較使用custom，該路徑維持原樣。
- 日買進金額／筆數採券商回報及本地可核對承諾的較大值，不重複加上已包含的掛單占用。

這些修正不代表每筆虧損是 bug。盤勢反轉、停損穿價、隔夜不能當沖與費稅侵蝕均可能是正常市場／策略風險。

## 研究開關與參數

| 設定 | 預設 | 研究行為 |
|---|---|---|
| portfolio_risk_enabled | false | 高點／回撤、連敗、近期負期望值、廣度／波動代理縮放 |
| portfolio_components | all | 可獨立設 drawdown／regime／loss_streak，供機制分解；追加分解屬探索性，不選參數 |
| portfolio_drawdown_fraction | 0.04 | 比較 0.03／0.04／0.05，不自動選贏家 |
| portfolio_cooldown_sessions | 2 | 比較1／2／3個已觀測交易日，重啟不重設 |
| portfolio_loss_streak | 3 | 完整 flat-to-flat 虧損次數，部分成交不重複計數 |
| entry_quality_enabled | false | 可解釋評分與追高、壓力空間、ATR、資料時間檢查 |
| research_exit_mode | baseline | fixed／atr_trail 獨立比較；不得放鬆已有保護底線 |
| max_portfolio_stop_fraction | 0 | 可選所有持倉同時觸停損的壓力預算；缺保護拒絕新增 |
| prompt_compaction | false | 截短歷史文字備註與重複檢討，保留所有數值行情／限制 |
| execution_slippage_bps（回放請求） | 0 | 實際模擬買賣報價各往不利方向移動；比較使用10／30／50bps |

研究設定須透過模擬進階設定或比較工具明確啟用；新增策略研究功能禁止 live／readonly。高點量測在 gate 關閉時仍保存，但不改變交易。高點無法自動辨識外部入提款；需另提供資金流資料才能作單位淨值調整，本版不憑空歸因。

市場代理只使用 asof 前已完成且七日內的動態池日資料，至少五檔；不把它冒充完整大盤。實際大盤指數目前只作外部比較基準，不參與進場。公司行動、存活者、商品資格、實際零股隊列不足皆列為限制。

## 公平比較與限制

完整預定條件見 `validation/v025/protocol.json`。逐組結果保留於 PR #28 與交付報告，執行比較工具會生成 comparison.json 及完整逐筆 run-audits。原36組預定比較之外，另加6組機制分解（回撤／市場代理／連敗各自獨立）；因已觀察組合結果，這6組標為探索性，不充當新未見樣本或選參依據。2026-09-16～10-16 排除於參數選擇與樣本外結果。2024上半年只作暖機／預先定義假說，Q3、Q4分開測試，每段本金100,000；不從測試結果擬合參數。A 使用 v0.2.4 原始 programAnalysis，其他組共用修正後的會計、撮合、費率和授權風控。A 是未改策略假說的規則基準，不是缺少完整分鐘資料的舊 AI 交易精確重跑，也不是宣稱舊 active 與本版資金限制相同。

E_research_combined 是預先固定4%／2日的研究組合，並未自動通過驗證。正式預設只納入安全修正；所有可選策略保持關閉。報告列出每組、每段及壓測，不因結果差而刪除。

資料來自證交所 dated MI_INDEX，另以官方年度交易／交割日曆與附來源的2024颱風公告核對。缺行情不直接認定休市。臨時公告的精確前日晚間分鐘未恢復，保守以休市當日00:00作可知截止，未在此前提供該休市資訊。逐日前一日成交金額 top40，自動股票池按日變動，並非根據本次贏家硬編。四位數代碼只是普通股候選代理，不是完整歷史證券主檔；不含 OTC、未還原權息、歷史處置／注意與停牌資訊不完整。日資料只可作保守開收盤近似，不能驗證盤中 ATR 退場或真實零股報酬。任何「樣本外」在此皆指時間隔離的研究比較，並非已證實長期期望值或可上實盤。

AI low／medium／high 沒有相同資料的已記錄對照輸出，因此不提供虛構收益排行或價格推估。新增提示 bytes／SHA256 遙測和可選壓縮，完整數值仍交由確定性程式處理；不修改預設推理程度、不呼叫付費模型測試，也不讓 AI 繞過 Risk。

## 測試、登入與回滾

單元／整合／回放涵蓋授權上限、股數二次確認後資產變動、合併持倉、跨日冷卻、重啟、部分成交、資料時間、漲跌停、缺失行情、公司行動、提示壓縮、完整匯出及報表還原。既有登入／CA、安全診斷、行情、撤單、重連、鎖檔、排程與 Windows 來源／封裝 GUI 檢查須全部通過才發行。

策略回滾：關閉 portfolio／entry_quality／prompt_compaction，exit_mode=baseline；原始策略來源另保留 v0.2.4。完整程式回滾可切換 v0.2.4 並先備份資料庫，但舊版會重新帶回已知安全缺口，不建議用它自動下單。新高點狀態獨立存於 portfolio_risk_v1，不移除原始委託、保護、交割或重複委託資料。
