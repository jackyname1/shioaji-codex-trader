# 連線、模擬與資料說明

## Codex 登入與連線

啟動時透過內建官方 CLI 的 `login status` 檢查共用登入快取；可沿用同一位使用者既有的檔案式 Codex 登入，不複製其個人 MCP 或工具設定。沒有登入時按右側「登入」，程式會開啟官方網址並顯示目前進度；也能重新開啟登入頁。瀏覽器回呼受阻時可用「裝置登入」，在官方頁面輸入畫面中的一次性代碼。完成後自動啟用 Codex，模擬與實盤共用同一登入。

「測試連線」會送出一個簡短、禁止工具的模型請求，用來確認登入與模型回應；會使用少量 Codex 額度。模型留空時先由官方 `model/list` 解析預設，再明確指定該模型，畫面列出實際模型及推理強度；目錄本身不代表帳戶具有模型使用權，完成模型回應才算連線成功。登入失效、模型不可用、額度與網路錯誤會保留具體原因。

Codex 控制台顯示官方回傳的推理摘要、分析步驟、原始結構化回覆與 token 用量。完整輸入快照、策略及數量建議、送單結果會保存；「完整紀錄」可搜尋及匯出全部 JSON，重啟後即時紀錄仍可檢視。秘密與原始 CLI 診斷不進入此紀錄。推理內容使用 SDK 提供的正式摘要。

本次重整的 v0.1.0，連線失敗的 details 保存允許的分類碼：DNS_FAILURE、TLS_CERTIFICATE、PROXY_AUTH、CONNECTION_REFUSED、CONNECTION_RESET、STREAM_INTERRUPTED、HTTP_SERVER_ERROR、NETWORK_TIMEOUT 等；無法辨識時是 NETWORK_UNSPECIFIED。子程序退出為 PROCESS_EXIT／PROCESS_SIGNAL，另有 TURN_FAILED、STREAM_ERROR、ITEM_ERROR、STREAM_PROTOCOL、EMPTY_OUTPUT 和 SDK_FAILURE；這些本機或回合故障也會停止自動呼叫。exit_code 只保存數字，exit_signal 只保存已知訊號。proxy_configured 與 custom_ca_configured 僅表示有設定，不包含值。這些是診斷線索，並不能單獨證明 VPN、代理或 OpenAI 服務是根因。

網路、登入、權限、模型、額度、限流、本機執行與逾時故障會停止自動 Codex 呼叫。即時模式繼續核對帳戶、掛單及持倉出場條件；未確認股數不送單，保留條件不代表斷線時仍能完成停損。修復後按「測試連線」，成功回應才解除故障；日策略失敗時還需重新分析。暫停、緊急停止與實盤授權保持原狀。歷史回放會停止於故障時刻，保存 PARTIAL 結果，其餘比較不執行，恢復後重新開始測試。

明確設定的 HTTP_PROXY、HTTPS_PROXY、ALL_PROXY、NO_PROXY 及 CODEX_CA_CERTIFICATE／SSL_CERT_FILE 會傳給 Codex，包括大小寫不同的環境變數。需要企業代理或自訂根憑證時，依組織提供的配置處理；不要關閉憑證驗證，也不要把代理帳密或憑證路徑貼在對話中。

更新版本前先從系統匣「結束程式」，再開新 EXE；單一執行個體機制會把第二次啟動導回仍執行中的舊版本，可從匯出 JSON 的 version 核對實際版本。

歷史模擬不查詢實盤銀行餘額、個人庫存或委託回報；真實行情登入完成並確認共用 Codex 登入後，即可執行完整歷史策略。執行中的失敗活動會保留在右側控制台。

## 連線

Windows 程式已內建官方 Shioaji 1.7.7，不需要安裝 CLI、調整 PATH 或填寫服務網址。在「帳戶與設定」輸入 API Key、Secret Key 即可連線；實盤下單才需要有效 CA。程式自動挑選專用連接埠，不覆蓋其他應用的服務。

建置流程下載固定版本的官方檔案，核對官方發布的 SHA-256 後封裝；啟動時再次驗證內建執行檔。使用者資料以模式與帳戶識別，連接埠變更不會建立新的模擬帳戶。API Key、Secret Key 與 CA 密碼以子程序環境變數傳入，不放進命令列、設定 JSON、日誌或 Codex 提示詞。

「記住設定」使用作業系統的加密儲存。系統加密不可用時不會降級成明文保存。未勾選時只使用本次輸入；重新啟動需要再次輸入。勾選後，程式會在下次啟動自動建立連線。程式退出只關閉它自己啟動的官方服務。

重新開啟帳戶設定時，已記住的 Key、Secret、CA 路徑與密碼會填回欄位；秘密使用密碼欄位遮蔽，只有開啟設定才讀取，不包含在畫面狀態輪詢或匯出紀錄中。尚未儲存的輸入不會被背景更新覆蓋；「清除記憶」也會清空欄位。

模擬與實盤均核對官方 `/info` 的正式服務狀態。`SJ_PRODUCTION=true` 代表取得正式市場行情；模擬的委託仍只進入本機 PaperBroker。登入、API/CA、帳戶選擇、Codex 模型/指令、排程與風控設定共用；模擬資金與真實帳戶、委託、策略及經驗分開保存。舊版模式設定自動遷移至共用設定；自動交易與實盤授權不會持久化沿用。

## 歷史資料與圖表

股票歷史資料由 Shioaji 官方分鐘 K 線取得，起始日為 2020-03-02。每次下載最多 30 個日曆日，使用排隊限速；已完成資料驗證後存入快取，當天資料重新下載並限制在本次可取得的最新時間。圖表資料只在載入或換股票／區間時查詢；盤中更新來自行情串流。

歷史測試可指定日期與分鐘，結束時間若為今天會限制在現在。自動股票池每天依前一交易日歷史成交金額排行更新，上限沿用 candidate_pool_size；保存當日成員與排行日期，不提前展示之後才入池的股票，離池持倉仍保留監控。也可指定本次要測試的固定股票池。每日資料池仍為設定的 20–100 檔，整段回測的累計股票聯集可超過 100 檔。每檔首次入池前的完整可用分鐘資料整理成每日 OHLC、成交量與成交金額供指標暖機；入池日至截止保留可用分鐘行情，離池後仍可監控持倉。暖機日 K 不作為分鐘價格事件或模擬成交深度。範圍最多 367 天，分鐘行情與暖機日 K 合計最多 300 萬筆；超過實際資料量時要求分段，每日排行不截斷。完整 JSON 保留每日股票池、入池日期、暖機日 K 與分鐘行情；分鐘 CSV 不含暖機及股票池。日 K 圖含暖機資料，分鐘圖只含入池後行情。

Shioaji 的排行旗標 `ascending=true` 是由大至小，本程式與官方 Pro 一樣使用此值，回放與即時模式共用同一掃描入口。分鐘 K 線 `Volume` 由張換為股一次，`Amount` 已是新台幣，不再乘以 1000；選股指標優先加總官方成交金額，資料未提供完整成交金額時才以收盤價乘成交股數估算並標記來源。舊版行情快取會自動重新取得。

原始行情與報表分別保存，可在重啟後查看或匯出。畫面顯示最近的成交與執行步驟；JSON 匯出包含全部選股、條件、風控、委託與成交流程，沒有截斷紀錄。圖表選擇 1／5／15／60 分鐘或日 K；MA、20 期兩倍標準差波動帶、簡單 RSI14、成交量與交易標記使用選定週期的資料。拖曳圖表可平移，滾輪以游標為中心縮放，拖曳右側價格軸可改變價格尺度；雙擊重設，或按「全覽」「最新」。底部時間軸與顯示根數同步，全部已知行情在畫面內時時間軸會停用。左右方向鍵平移、加減鍵縮放、Home/End 前往最早／最新。更新行情不會重設正在檢視的歷史位置。當前聚合 K 棒在尚未完成時只使用目前已取得的價格。

歷史資料在快取與回測之前依股票與時間整理：完全相同的紀錄只保留一筆，同批 Shioaji 修訂採最後有效值，成交量不加總重複資料；排行中的同一股票只下載一次。報表保留整理數量。CSV 可包含 `amount_twd`，相同重複資料可自動整理，價格、成交量或成交金額衝突會顯示股票與台北時間，需要核對原始資料。

## 模擬策略與回放

「即時模擬」使用正式行情與本機虛擬資金，委託不送給券商；帳戶及委託分開保存，流程與實盤共用。按「開始自動交易」建立首輪條件，之後依帳戶設定的每日固定時間或間隔更新快照、Codex 選股與條件。短週期依條件偵測、數量確認、送單與成交核對。賣款保留至 T+2，不立即變成新買進預算。

每輪 Codex 必須處理持倉出場條件及候選／監測股票的買進條件，持倉與未完成委託立即留在監測清單。個股策略的股數是參考；價格條件真正觸發時，程式先取得目前帳戶、掛單占用、可用現金、可賣庫存及行情，再呼叫 Codex 決定實際幾股／幾張與限價。Codex 可選擇 HOLD，沒有有效回覆不送單。SELL 優先確認；同一股票只保留一個確認請求，送出前再次核對條件、策略、設定、連線與風控。數量確認期間仍持續核對成交，緊急停止會立即使未送出的建議作廢。

5–20 檔是合格候選的目標，不是成功分析的最低數量；不足時只使用合格股票。`HOLD_ONLY` 搭配空候選是有效的保留現金策略，回放會繼續跑完後續排程與檢討；持倉出場保護仍須完整。每次分析前，Codex 紀錄會顯示資料池、歷史就緒及基本資格數；歷史不足、過期或請求失敗會保留每檔具體原因，暫時失敗不快取為成功，之後會重新查詢。快照也提供價格限制、可用現金、最低保留額、買進預算及每日損失基準，避免模型因缺少程式已有資料而拒絕分析。

桌面歷史回放只有 **Codex 每日選股** 完整策略：每個交易日依固定時間或分析間隔建立歷史快照，等待選股與條件完整回傳並驗證。條件觸發後，另等待 Codex 依當時現金確認股數，再執行風控、模擬委託、費稅及成交核對。盤後另執行當時的檢討。呼叫上限包含選股、數量確認與檢討；預算耗盡不跳過數量確認送單。程式策略與虛構流程只保留給離線開發測試。

「歷史回放」只執行虛擬時間的策略，不另啟動即時策略；切到回放會關閉即時模擬的自動執行。回放仍在執行時先停止再切到即時模擬。兩種模擬與實盤的帳戶、圖表、條件和活動紀錄使用各自的時間及資料。

回放速度只影響事件等待，不改變行情時間、策略排程或成交順序。「直達觸發點」直接進入下一事件，仍逐一等待 Codex 選股、策略驗證、條件偵測、股數確認、送單與核對；模型處理期間虛擬時間保持不動。可暫停、繼續、完整執行下一事件後暫停；跨日空白時間會略過，盤中等待依設定倍率縮短。執行中的本輪參數固定，畫面顯示當前步驟及下一觸發時間；失敗原因、選股門檻與委託狀態保存在完整報表。AI 快照、指標、價格、歷史經驗與行情圖表都受伺服端模擬時間限制；不從前端指定未來資料截止點。

歷史 K 線無法重建零股撮合排隊或當根 K 線內的觸價先後。缺少零股歷史五檔時，以成交量參與比及一個 tick 的價差估算。費率可自訂，損益計入手續費、普通現股賣出稅及 T+2 賣款。期末持倉以最後價格估值。歷史排行、目前契約表與企業行動不完整時，報表保留限制與資料覆蓋狀態。Codex 的預訓練知識也可能含歷史事件。

## 實盤

切換「實盤」直接開啟帳戶監控；已保存的連線設定共用。CA、帳戶與委託核對完成後自動就緒，不需「啟動實盤」或另外授權。「開始自動交易」獨立控制 Codex 策略的自動執行，重啟保持關閉。內建手續費估計（0.001425、最低 NT$20）與交割預留，不需勾選費率確認或選擇交割正負號。費率可自行調整。所有未完成交割金額以絕對值預留，未入帳收款不增加可用現金；這可能保留比實際待付款更多的資金。帳務載入失敗會顯示原因並自動重試，行情登入與歷史模擬仍可使用。Codex 登入與設定為兩種模式共用。

本次就緒狀態只存在程式記憶體，綁定已核對的券商帳戶。重開或重新連線會重新核對，保持自動交易關閉；緊急停止、鎖定或變更交易風控會關閉交易與自動執行；舊版 SQLite 授權紀錄不會沿用。一般暫停／恢復保留本次授權。每筆委託仍重新核對正式服務、CA、帳戶、行情、委託狀態及風控。只有撤單的確認僅開放本程式掛單的撤單，不能啟動新買賣。程式只交易上市櫃普通現股，使用現股限價單，禁止今日新增股數當沖。

帳戶識別使用券商帳號與正式／模擬服務身分，不包含自動挑選的連接埠。舊版埠號識別只在原券商帳戶雜湊完全吻合後升級；換券商帳戶仍拒絕混用資料庫。API、模式與帳戶設定變更互斥，緊急停止不會被尚未完成的啟動流程解除。撤單回應中增加的成交量仍記錄一次，不遺漏、不重複。

預設保留現金 25%、單筆 10%、單檔 20%、總持倉 75%、每日新增買進 20%、每日最多 5 筆，日損失 2% 停止新買進。行情或帳戶過期、未知委託、回報中斷或未確認交易日會停止新增委託。智慧停損由本機程式監測，需程式及網路持續運作。

暫停買進會處理本程式進場掛單並保留保護監測。緊急停止阻止所有新委託；既有掛單可在主視窗的委託面板另行核對撤單。期貨、選擇權、融資融券、槓桿及反向 ETF 不開放。介面及圖表為本專案自行實作，參考 Shioaji Pro 的操作流程。

## 驗證

`npm test` 使用測試行情與隔離帳戶驗證風控、成交、歷史時間限制、資料快取、回放控制、憑證保存與 SDK 活動事件。測試另涵蓋預設設定、degraded 行情服務、缺少 CA、首次帳務失敗後自動恢復、舊設定遷移、只使用行情端點的完整模擬，以及以隔離程序完成 Codex 瀏覽器／裝置登入與模型回應診斷。Windows CI 另驗證單一工作台在三種解析度的完整顯示、模式版面切換、常駐 Codex、安全 IPC、帳戶視窗、圖表、系統匣與打包後 EXE；另以空白 PATH 啟動內建 Shioaji 驗證版本。建置會產生程式截圖及可下載的執行檔。開發與 CI 不使用使用者的券商或 Codex 帳戶。

本次依使用者要求重整為 0.1.0：先驗證新執行檔與下載檔，再替換舊 0.1.0 並刪除已列明的其他 Release。Git 歷史與其他版本的 tag 保留。之後的新版本仍各自發布，不覆寫已發布版本；相同版本的重跑只核對相同提交與檔案雜湊。

## 實盤連線診斷

右上角「診斷」顯示各端點讀取結果、HTTP 狀態、最後成功時間、重試時間及服務／CA 狀態，不會因為開啟視窗增加券商查詢。匯出 JSON 不包含帳號、金鑰、憑證密碼或帳務內容。HTTP 429 依 Retry-After 等待；session 恢復期間保留既有帳務並暫停新委託，恢復後重新核對。回報訂閱遺失會在 cache health 確認 NotSubscribed 後訂閱，避免覆蓋 cached login 保留的回報。

### 本機紀錄恢復

顯示「Shioaji 已連線 · 帳務可讀，本機紀錄待修復」時，診斷會指出本機失敗步驟，例如建立資料庫鎖、核對鎖擁有者、開啟 SQLite 或驗證紀錄保存。Windows 使用使用者資料夾的 ACL 保護紀錄，不對已開啟的資料庫套用 Unix chmod。

確認舊版已從系統匣「結束程式」後，在診斷按「重試本機紀錄」。程式會重新開啟同一份資料庫、讀取原本委託及成交紀錄，並重新讀取帳務與委託；沿用現有 Shioaji 登入。恢復後自動交易保持關閉，核對完成後可自行開始。

只有已確認結束的程式、可證明 PID 已被其他新程序重用，或本程式已關閉資料庫並釋放權限的鎖，才可清理。仍在執行、擁有者不明或鎖內容損壞時，保持帳務唯讀並保留原紀錄。若失敗步驟是建立檔案或保存紀錄，先恢復使用者資料夾的寫入權限，再按重試。請保留資料庫與 SQLite 的 WAL 檔案，避免遺失尚未核對的委託。

Windows 發行者與簽章參見 [WINDOWS_SIGNING.md](WINDOWS_SIGNING.md)；產品名稱中繼資料不能取代可信簽章。

### 歷史回放的完整策略

歷史回放只有 Codex 完整策略：依每日固定時間或更新間隔選股，設定觀測股買進與持倉賣出標準；程式在交易時段每五分鐘檢查，觸發後以當時帳務再次請 Codex 確認數量與限價，再通過風控送出模擬委託。分鐘行情仍逐筆核對既有委託成交，不能在五分鐘檢查之外新增買賣提案。

「直達觸發點」依序完整執行五分鐘檢查，不跳過中途條件；遇到觸發或下一次 Codex 排程，等待完整結果後才繼續。選擇「加速播放」可用拉桿或精確欄位調整 1–60 倍，預設 10 倍；秒數連續前進，60 倍時五分鐘約需現實五秒。直達模式停用倍速控制。暫停、事件處理、Codex 分析與股數確認時，時鐘凍結；恢復不補跳等待期間的秒數。夜間及休市日略過；盤中依事件時間差連續播放。倍速只改變等待，不改變策略、行情與成交。

資料池內但未入選的股票可用 HOLD、smart=null 說明排除理由；不因此取得買進資格。未知股票、非候選 BUY 及未持有股票的交易決策仍拒絕。程式規則與虛構流程僅供離線開發測試，桌面回放入口不提供策略切換。

額外必要條件以 `decisions.conditions` 列出並全部同時成立：例如 `LAST GTE MA20`、`MA5 GTE MA20` 或 `LAST GT VALUE 625`。固定價格條件仍由 entry_when／trigger_price 表示；reason 只作說明。缺指標、非有限數字、未來或盤中未完成日 K 都不滿足指標條件。股數回覆後及最後送單前再次核對，不以舊觸發狀態送單。舊版計畫可讀，但要取得新條件欄位需重新執行 Codex 分析。

盤中指標只使用前一交易日及更早的日 K；13:40 以後有當日收盤資料才納入當日，晨間快取與盤後快取分開。今日參考價與漲跌停不隨盤後日 K 改寫。

額度耗盡或限流會在當下停止回測與剩餘比較，保存 PARTIAL 報表及實際截止時間，取消尚未成交的模擬委託，未確認的股數不會送單。額度恢復後重新執行，不支援從停止時的模擬帳戶續跑。一般暫時網路／格式問題仍保留失敗原因，後續排程可重新分析。

股數快照提供上限數量的買賣手續費、賣出稅及停利淨價差估算；模型仍需依實際建議數量重算，最低手續費不隨股數等比例減少。報表顯示費用前損益、已支付費稅與成本占起始資金比例，不含未來平倉費用。近似成交、賣出成交明細數與小樣本警示不應當作實盤獲利或完整交易勝率；回測等待模型會凍結價格，實盤不會。
