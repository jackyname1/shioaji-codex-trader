# 連線、模擬與資料說明

## Codex 登入與連線

啟動時透過內建官方 CLI 的 `login status` 檢查共用登入快取；可沿用同一位使用者既有的檔案式 Codex 登入，不複製其個人 MCP 或工具設定。沒有登入時按右側「登入」，程式會開啟官方網址並顯示目前進度；也能重新開啟登入頁。瀏覽器回呼受阻時可用「裝置登入」，在官方頁面輸入畫面中的一次性代碼。完成後自動啟用 Codex，模擬與實盤共用同一登入。

「測試連線」會送出一個簡短、禁止工具的模型請求，用來確認登入與模型回應；會使用少量 Codex 額度。模型留空使用帳戶預設。登入失效、模型不可用、額度與網路錯誤會顯示可採取的處理方式；原始 CLI 輸出、token 與模型私有推理不會轉送到畫面或交易日誌。

歷史模擬不查詢實盤銀行餘額、個人庫存或委託回報；真實行情登入完成即可執行「快速程式策略」。Codex 模式在開始前核對共用登入，執行中的失敗活動會保留在右側控制台。

## 連線

Windows 程式已內建官方 Shioaji 1.7.7，不需要安裝 CLI、調整 PATH 或填寫服務網址。在「帳戶與設定」輸入 API Key、Secret Key 即可連線；實盤下單才需要有效 CA。程式自動挑選專用連接埠，不覆蓋其他應用的服務。

建置流程下載固定版本的官方檔案，核對官方發布的 SHA-256 後封裝；啟動時再次驗證內建執行檔。使用者資料以模式與帳戶識別，連接埠變更不會建立新的模擬帳戶。API Key、Secret Key 與 CA 密碼以子程序環境變數傳入，不放進命令列、設定 JSON、日誌或 Codex 提示詞。

「記住設定」使用作業系統的加密儲存。系統加密不可用時不會降級成明文保存。未勾選時只使用本次輸入；重新啟動需要再次輸入。勾選後，程式會在下次啟動自動建立連線。程式退出只關閉它自己啟動的官方服務。

模擬與實盤均核對官方 `/info` 的正式服務狀態。`SJ_PRODUCTION=true` 代表取得正式市場行情；模擬的委託仍只進入本機 PaperBroker。登入、API/CA、帳戶選擇、Codex 模型/指令、排程與風控設定共用；模擬資金與真實帳戶、委託、策略及經驗分開保存。舊版模式設定自動遷移至共用設定；自動交易與實盤授權不會持久化沿用。

## 歷史資料與圖表

股票歷史資料由 Shioaji 官方分鐘 K 線取得，起始日為 2020-03-02。每次下載最多 30 個日曆日，使用排隊限速；已完成資料驗證後存入快取，當天資料重新下載並限制在本次可取得的最新時間。圖表資料只在載入或換股票／區間時查詢；盤中更新來自行情串流。

歷史測試可指定日期與分鐘，結束時間若為今天會限制在現在。自動股票池來自開始日前的歷史成交金額排行；也可指定本次要測試的股票。每一檔會取得區間內可用的完整分鐘行情及前置暖機資料，不以抽樣 K 線代替原始資料。範圍最多 367 天、最多 100 檔及 300 萬筆；大型測試可分段進行。

原始行情與報表分別保存，可在重啟後查看或匯出。圖表選擇 1／5／15／60 分鐘或日 K；MA、20 期兩倍標準差波動帶、簡單 RSI14、成交量與交易標記使用選定週期的資料。滑動時間軸可逐段檢查整個區間。當前聚合 K 棒在尚未完成時只使用目前已取得的價格。

## 模擬策略與回放

- **快速程式策略**：MA5 ≥ MA20、價格 ≥ MA20，依成交額、量比、RSI30–75 與 20 日報酬篩選；單檔配置上限 5%，停損 5%、停利 10%、移動停損 3%。同時遵守使用者設定的更低風控上限。
- **Codex 逐輪判斷**：依虛擬時間建立快照與分析，程式執行條件、委託、費稅及風控。模型／推理強度使用本機 Codex 支援的選項，模型識別碼可自行輸入。

模擬模式不會在背景另啟動現在時間的 Codex 策略；主視窗分析按鈕使用相同歷史模擬流程。實盤模式才啟動現在時間的策略排程。

回放速度只影響畫面與事件等待，不改變行情時間、策略排程或成交順序。可暫停、繼續、逐事件前進；夜間空白時間會壓縮，最快估算不等待。AI 快照、指標、價格、歷史經驗與行情圖表都受伺服端模擬時間限制；不從前端指定未來資料截止點。Codex 活動視窗顯示執行階段與公開決策理由，不保存模型的私有推理內容。

歷史 K 線無法重建零股撮合排隊或當根 K 線內的觸價先後。缺少零股歷史五檔時，以成交量參與比及一個 tick 的價差估算。費率可自訂，損益計入手續費、普通現股賣出稅及 T+2 賣款。期末持倉以最後價格估值。歷史排行、目前契約表與企業行動不完整時，報表保留限制與資料覆蓋狀態。Codex 的預訓練知識也可能含歷史事件。

## 實盤

切換「實盤」直接開啟帳戶監控，不會啟用交易，也不要求 CA。主視窗「啟動實盤」先自動核對 CA、登入、帳戶與委託，顯示遮罩帳號與目前風控，只需按一次確認就完成授權並啟動。不需輸入授權文字或設定 `LIVE_TRADING`。內建手續費估計（0.001425、最低 NT$20）與交割預留，不需勾選費率確認或選擇交割正負號。費率可自行調整。所有未完成交割金額以絕對值預留，未入帳收款不增加可用現金；這可能保留比實際待付款更多的資金。帳務載入失敗會顯示原因並自動重試，行情登入與歷史模擬仍可使用。Codex 登入與設定為兩種模式共用。

本次授權只存在程式記憶體，綁定已核對的券商帳戶。重開、重新連線、緊急停止、鎖定或變更交易風控會關閉授權與自動執行；舊版 SQLite 授權紀錄不會沿用。一般暫停／恢復保留本次授權。每筆委託仍重新核對正式服務、CA、帳戶、行情、委託狀態及風控。只有撤單的確認僅開放本程式掛單的撤單，不能啟動新買賣。程式只交易上市櫃普通現股，使用現股限價單，禁止今日新增股數當沖。

帳戶識別使用券商帳號與正式／模擬服務身分，不包含自動挑選的連接埠。舊版埠號識別只在原券商帳戶雜湊完全吻合後升級；換券商帳戶仍拒絕混用資料庫。API、模式、帳戶設定與確認視窗互斥，緊急停止不會被尚未完成的啟動流程解除。撤單回應中增加的成交量仍記錄一次，不遺漏、不重複。

預設保留現金 25%、單筆 10%、單檔 20%、總持倉 75%、每日新增買進 20%、每日最多 5 筆，日損失 2% 停止新買進。行情或帳戶過期、未知委託、回報中斷或未確認交易日會停止新增委託。智慧停損由本機程式監測，需程式及網路持續運作。

暫停買進會處理本程式進場掛單並保留保護監測。緊急停止阻止所有新委託；既有掛單可在主視窗的委託面板另行核對撤單。期貨、選擇權、融資融券、槓桿及反向 ETF 不開放。介面及圖表為本專案自行實作，參考 Shioaji Pro 的操作流程。

## 驗證

`npm test` 使用測試行情與隔離帳戶驗證風控、成交、歷史時間限制、資料快取、回放控制、憑證保存與 SDK 活動事件。測試另涵蓋預設設定、degraded 行情服務、缺少 CA、首次帳務失敗後自動恢復、舊設定遷移、只使用行情端點的完整模擬，以及以隔離程序完成 Codex 瀏覽器／裝置登入與模型回應診斷。Windows CI 另驗證單一工作台在三種解析度的完整顯示、模式版面切換、常駐 Codex、安全 IPC、帳戶視窗、圖表、系統匣與打包後 EXE；另以空白 PATH 啟動內建 Shioaji 驗證版本。建置會產生程式截圖及可下載的執行檔。開發與 CI 不使用使用者的券商或 Codex 帳戶。
