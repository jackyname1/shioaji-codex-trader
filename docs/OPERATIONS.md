# 操作與資料說明

## 帳戶與登入

「帳戶與設定 → 帳戶連線」輸入 API Key、Secret Key。程式使用內建官方 Shioaji，無須自行安裝 CLI 或填寫服務網址。有效 CA 與密碼用於實盤；記住設定使用作業系統加密，系統加密不可用時不會降級保存明文。

登入、模型及一般偏好在模擬與實盤共用，執行帳戶與行情仍依工作區隔離。歷史回測不讀取個人實盤持倉、銀行餘額或委託回報。切換模式與重新啟動不會自動開始交易。

Codex 使用官方登入；可沿用同一使用者既有登入快取，或從控制台開啟瀏覽器／裝置登入。「測試連線」會使用少量模型用量。模型留空時解析帳戶預設，畫面顯示實際模型與推理強度；清單不代表帳戶具備使用權，成功回覆才算連線完成。

## 設定與用量

主設定頁提供五個分類，完整參數與預設值見 [設定參數](SETTINGS.md)。模型及推理強度在右上控制台直接調整。

日常預設每天 09:15、11:45，最多 2 次；回測預設每 5 個交易日於 09:15 分析，跨日間隔可設 1–20，整次／整批最多 20 次只作預算保護。策略啟動、手動分析、失敗及額外股數確認納入相應上限；程式監測與持倉保護不消耗模型。重啟不重設已保存的日常次數。回測休市日不計入跨日間隔；已知交易日即使缺行情仍計入，缺資料會另行標記。間隔從起點之後第一個可執行的分析時刻開始。

「歷史回測」分類保存獨立的跨交易日間隔、分析日內排程、時間、分鐘間隔、用量、股數方式及額外檢討。儲存後同步到回測頁，執行中的測試沿用啟動時設定。回測工具列 ⚙ 可改本次資料與成交假設；啟動時保存模型用量偏好。一般設定更新不覆蓋尚未開始的回測草稿。

固定時間使用逗號分隔，可設 1–6 個不重複的 08:00–13:29 時間。分析日內的分鐘間隔與固定時間擇一；盤後檢討須另外勾選，僅在分析日執行，亦受次數上限約束。非分析日持續更新行情、檢查有效條件及持倉保護，但不會自動延長策略期限。若下一個必要模型步驟超過設定預算，立即停止並保存部分結果，不讓剩餘期間繼續以停止更新的策略跑完。

## 版面與速覽

主視窗左側是持倉、監測清單與個股資料，中間是圖表及委託／回測結果，右上為模型與簡要紀錄，右下是股票策略總覽。策略表列出觸發、限價、參考股數與保護狀態，可放大；條件觸發後重新核算最終股數。

單擊系統匣開啟速覽，雙擊開啟主視窗。速覽順序為基本資料、持倉、策略、監測、委託，可自訂顯示區塊與隱藏金額。點股票連動主圖，Esc 或點外部收起。未實現損益是尚未扣除退出費稅的毛利；資料不完整時顯示「—」。

## 進場、保護與資金

程式先核對條件，再依策略參考股數、現金、費稅、掛單及可賣庫存核算數量。新增風險遵守保留現金至少 25%、單筆不超過扣除保留後資金 10%、單檔 20%、總持倉 75%、每日新增 20%／5 筆、日損失 2% 停止買進；較嚴格設定保留。

回測「標準風控」的積極／平衡名稱只用於讀取相容，不放寬界線；標準配置另要求扣費報酬風險比至少 1.2、單筆停損預算不超過權益 1%。「目前自訂風控」使用已儲存門檻，仍受強制界線約束。

反彈買進先跌到門檻才追蹤低點，回升指定比例再提案，買價上限及 AND 條件持續生效。固定停損優先，移動退場越過啟動價後追蹤高點，回落指定比例才提案；收益目標僅估算成本與風險，不是賣出指令。智慧保護底線不放鬆，重啟保留追蹤。

今日新增零股不可當沖。賣款到已確認交割日 T+2 上午 11:00 才可使用；缺少日曆時繼續預留。停損與保護價無法保證跳空、無買盤或斷線時成交。

研究選項預設關閉，包含多策略、動態配置、組合風險、進場評分及退場比較。尚未證明提高樣本外收益；研究風險與選股開關禁止套用 live／readonly。

## 歷史回放

每日股票池使用前一交易日歷史成交金額排行，每日 20–100 檔，聯集可超過 100 檔；也可指定最多 100 檔固定股票。入池前日 K 用於指標暖機，模型只讀取虛擬時間前已完成資料。

日期最多 367 天，分鐘行情與暖機日 K 合計最多 300 萬筆。超量明確停止，需分段回測；下載每次最多 30 個日曆日，並使用快取與節流。

預設逐筆可用分鐘行情檢查進場與保護，委託只能在送出後的行情成交。直達觸發點與 1–60 倍加速都依序處理事件；分析及暫停期間凍結虛擬時間。只有分鐘收盤價時不能推斷 K 線內路徑。

完整報表提供成交、費稅、資金、日損益與進場診斷；等待樣本不是獨立交易機會。可匯出完整 JSON、成交 CSV、行情；JSON 保留暖機與每日股票池，行情 CSV 僅含保留分鐘資料。歷史零股深度、排隊、企業行動及滑價仍有近似，不能以小樣本或測試資料證明實盤收益。

## 故障與停止

API 各端點獨立保存最後成功資料與安全錯誤；行情／帳務過期時不送單。「連線診斷」可匯出端點狀態與 SDK／程序錯誤，不包含金鑰、CA 密碼及帳務內容。

Codex 網路、登入、模型、用量與執行故障停止後續自動呼叫；修復後測試連線，日策略失敗需重新分析。即時持倉保護持續核對，緊急停止及可賣庫存限制仍生效。歷史故障保存 PARTIAL 結果，不冒充完整測試，其餘比較不執行。

「停止交易」阻止新委託，既有券商掛單須另外撤銷核對。完整 Codex 紀錄可搜尋與匯出快照、正式推理摘要、回覆、用量及結果；簡要控制台只顯示近期步驟。

更新前先從系統匣結束舊程式，再開新 EXE，避免單一執行個體機制導回舊版本。版本編號重設不清除設定、憑證、策略、帳務、快取或既有報表；報表格式版本獨立維持讀取相容。
